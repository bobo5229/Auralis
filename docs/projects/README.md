## 阶段材料怎么读

- `BASELINE` 是阶段开始时的基线，`TECHDOC` 是方案，`DELIVERY` / `IMPLEMENTATION-REPORT` 是交付记录，`REVIEW` 是对应范围的审查。
- 阶段按数字自然顺序查找：Phase 9 在 Phase 10 之前；缺少某阶段目录不自动表示漏做或待补。
- 截图目录中的 README 是当时证据说明，不代表一定存在截图，也不能替代当前视觉验收。
- 手稿皮肤[路线图](library-manuscript-skin-mvp/DELIVERY-ROADMAP.md)是旧状态快照，汇总与后续段落可能不一致；阶段交付也不能单独当作当前产品能力清单。实际工作前核对源码及相关更新记录。
- 文档中的后续阶段、延期容量检查与待确认项仅作追溯，不构成重新启动项目的授权。
