# Renderer 视觉与交互

施工者落实本文件中的界面约束并完成必要检查；验证范围与独立验收要求按[风险与验收](validation.md)判断。

普通主界面与全屏播放器共享播放状态。调整主 BrowserWindow 尺寸和生命周期时，验证主界面布局及全屏播放器的进入与退出。

播放状态沿用现有 playback composable，避免在 Renderer 建立互相竞争的状态来源。

## 临时状态与菜单交互

区分菜单高亮等临时交互状态、持久选择、播放状态与焦点。临时状态随所属界面关闭而结束；清理时保留仍有效的键盘选择、播放状态和焦点交接。按本次涉及的行为检查点击外部、Esc、执行操作、切换视图或离开页面等退出路径。

动态隐藏或移除菜单项时，同步核对分隔线、可操作项和键盘导航。导航与焦点定位使用稳定标识，避免依赖条件渲染后会变化的 DOM 序号；隐藏或禁用项不参与激活，后续可操作项仍能正确获得焦点。

## 动态布局与滚动

长内容先确定完整显示或容器内滚动。采用局部滚动时，明确滚动容器、可用高度和输入命中区域；隐藏滚动条后实际检查鼠标滚轮及本次涉及的其他输入方式。

动效、旋转、长文本或尺寸变化涉及相邻区域时，检查变换后的实际占用范围及过渡过程，并明确空间不足时的降级行为。歌词、信息区与碟片等相关层的边界一并核对，使用已确定的裁切、位置调整或隐藏策略。

## 动态背景与配色

背景随内容取色时，通过共享语义颜色变量联动该画布内的主次文字、歌词、轨道、分隔线和交互反馈。验证相关主题、开关状态及内容切换过程中的可读性，保持功能约定的主题和页面范围。

## 颜色 token 的影响范围

修改表面颜色前，核对 token 的定义、主题覆盖及实际消费者，包含组件样式、UnoCSS 配置和变量别名；明确本次改变共享 token 还是组件局部表面。沿用现有语义变量，修改范围与授权目标一致。相邻区域需要同步变色时，一并核对背景层、过渡属性和时长，避免同一画布分段更新。

## 材质与采样对象

毛玻璃需求先明确采样对象：CSS `backdrop-filter` 采样应用内部位于元素后方的内容；透出桌面或其他窗口需要系统窗口材质及透明层级配合。按当前 Electron 版本与目标系统核对能力、透明区域和不支持时的回退，不用应用内模糊代替桌面材质。

桌面材质的效果比较在真实原生窗口中进行，覆盖目标区域和主题；可以使用现有应用窗口，需要独立原型时按[风险与验收](validation.md#原型与音频效果)选择。HTML 原型只用于它能呈现的布局与交互。用户的主观反馈与已证实的技术问题分别记录。

## 通用文字规格

新增或修改普通界面文字时，优先使用 `src/renderer/app/styles/typography.css` 的语义字号与配套行高，避免新增散落的固定字号。模板可使用 `.auralis-type-*` 类，组件 CSS 可引用 `--auralis-type-*-size` 与 `--auralis-type-*-line-height`。

| 角色      | 用途                     | 字号 / 默认行高 |
| --------- | ------------------------ | --------------- |
| `caption` | 辅助提示、说明、计数     | 12px / 18px     |
| `control` | 菜单、标签、输入框、按钮 | 14px / 20px     |
| `body`    | 正文、主要内容           | 16px / 24px     |
| `section` | 弹窗标题、区块标题       | 18px / 26px     |
| `page`    | 页面标题                 | 24px / 32px     |

字号和行高成对使用；字体沿用现有字体角色，字重按信息层级选择，颜色使用对应语义色。图标不作为文字字号角色，现有尺寸规则继续适用。

曲目行、歌词、CD 浏览、声迹等已有专用排版保留各自规格。新增例外需在对应组件或规格文件中说明用途；涉及固定行高或虚拟滚动时，同步核对实际几何和估算指标。既有普通页面逐步迁移，不为统一字号一次性改动全部界面。

唱片室使用独立的 `--cd-type-*` 字号与行高角色，集中定义在 `cdTypography.css`；角色、几何例外和扩展规则见[唱片室语义字号体系](../topics/albums/TECHDOC-cd-room-semantic-typography-2026-10-04.md)。

曲库虚拟列表的 CSS 实际几何必须与 virtualizer 使用的估算高度一致；相关指标集中在 src/renderer/features/library/constants/libraryLayoutMetrics.ts。

细线粗细或缩放问题结合原始截图、运行时 `devicePixelRatio` 和实际坐标排查；非整数缩放效果须经实际渲染验证，静态检查不能替代视觉验收。绘制方案与检查方法按需参考[封面视图分割线与设备像素取整](../topics/library/TECHDOC-cover-track-divider-pixel-snapping-2026-09-28.md)。
