# Renderer 视觉与交互

施工者按本规则落实界面约束，并按[风险与验收](validation.md)完成必要检查。

普通主界面与全屏播放器共用现有 playback composable 的播放状态。调整主 BrowserWindow 尺寸或生命周期时，验证主界面布局及全屏播放器的进入与退出。

## 临时状态与菜单交互

区分菜单高亮等临时交互状态、持久选择、播放状态与焦点。临时状态随所属界面关闭而结束；清理时保留仍有效的键盘选择、播放状态和焦点交接。按本次涉及的行为检查点击外部、Esc、执行操作、切换视图或离开页面等退出路径。

动态隐藏或移除菜单项时，同步核对分隔线、可操作项和键盘导航。导航与焦点定位使用稳定标识，跳过隐藏或禁用项，确保后续可操作项能正确获得焦点。

## 动态布局与滚动

长内容先确定完整显示或容器内滚动。采用局部滚动时，明确滚动容器、可用高度和输入命中区域；隐藏滚动条后，实测鼠标滚轮及本次涉及的其他输入方式。

动效、旋转、长文本或尺寸变化涉及相邻区域时，检查变换后的实际占用范围及过渡过程，并明确空间不足时的降级行为。歌词、信息区与碟片等相关层的边界一并核对，使用已确定的裁切、位置调整或隐藏策略。

## 动态背景与配色

背景随内容取色时，通过共享语义颜色变量联动该画布内的主次文字、歌词、轨道、分隔线和交互反馈。验证相关主题、开关状态及内容切换过程中的可读性，保持功能约定的主题和页面范围。

## 颜色 token 的影响范围

修改表面颜色前，核对 token 定义、主题覆盖和实际消费者，包括组件样式、UnoCSS 配置与变量别名，并明确修改共享 token 还是组件局部表面。沿用现有语义变量，保持授权范围；相邻区域需要同步变色时，统一核对背景层、过渡属性与时长。

## 材质与采样对象

毛玻璃需求先明确采样对象：CSS `backdrop-filter` 采样应用内部位于元素后方的内容；透出桌面或其他窗口需要系统窗口材质与透明层级配合。按当前 Electron 版本与目标系统确认能力、透明区域和回退方案。

桌面材质效果在真实原生窗口中比较，覆盖目标区域和主题。可使用现有应用窗口；需要独立原型时按[风险与验收](validation.md#原型与音频效果)选择。HTML 原型用于布局与交互验证，主观反馈与已证实的技术问题分别记录。

## 圆角与嵌套关系

以 Apple macOS 的桌面组件与层级为主要参考，采用同心嵌套、同类一致和容器适应原则；具体数值由 Auralis 的组件尺寸和信息密度确定，不视为 Apple 官方标准值。

- **容器**：菜单、弹窗和参数面板按用途确定外壳半径；贴边或悬浮状态可采用不同形状，不机械统一为胶囊。
- **交互控件**：同一类控件复用形状规则。靠近外壳圆角的高亮项，以外壳半径减去实际内缩距离推导；内缩距离计入边框和中间包装层，普通圆弧的结果最低为零。居于容器内部的独立控件不强制同心。
- **内容封面**：按展示场景、尺寸和已有用户偏好处理，外扩框同步增加半径；不直接套用菜单或按钮的半径。
- **材质绘制层**：与外壳重合且 `inset: 0` 的图层继承同一轮廓；有内缩的图层按实际距离递减半径。
- **曲线类型**：普通圆弧与 Apple `continuous` 连续曲率分别判断。采用新曲线前验证当前 Electron 的渲染支持、内外轮廓与动画表现；不能用调大半径代替连续曲率。

菜单首批基线集中在 `src/renderer/shared/menu/menuGeometry.css`，消费方通过变量选择外壳规格，菜单项半径统一推导。通用磨砂菜单为外壳 `16px`、内边距 `4px`、无边框，菜单项为 `12px`；紧凑设置下拉保留外壳 `10px`、内边距 `4px`、边框 `1px`，选项为 `5px`。歌词保存菜单由内层 actions 提供同样的 `4px` 内缩，外壳不重复添加 padding。

播放栏“更多”菜单保留 `16px` 外壳与 `8px` 内缩，菜单项为 `8px`。播放队列采用 `24px` 外壳、`12px` 内缩、`12px` 行圆角；行内封面再内缩 `8px`，封面圆角为 `4px`。播放模式菜单保留贴边高亮，仅首尾项的外侧角递减外壳边框厚度；播放栏无边框时为 `24px`，全屏有 `1px` 边框时为 `23px`，中间连接角为直角。歌词保存菜单收拢动画读取实际按钮圆角，展开轮廓读取菜单自身圆角。

弹窗与参数面板基线集中在 `src/renderer/shared/styles/panelGeometry.css`：常规居中弹窗、紧凑重命名弹窗和独立侧面板共用 `20px` 外壳；贴顶页面参数面板保留顶部直角、底部 `16px`。弹窗操作、关闭和设置导航控件共用 `8px` 圆角，它们与外壳角落有足够间距，作为独立控件处理。曲目编辑弹窗复用通用外壳与操作按钮规格，不另设相同职责的半径；封面仍按内容场景保留原有规则。设置分组与全屏参数分组位于较深内缩处，保留 `13px` 内容分组圆角；徽章收藏盒由自身的实体外壳定义轮廓，透明对话框宿主保留 `0px`，不套用常规面板外观。

封面基线由 `src/renderer/shared/artwork/artworkCorners.ts` 定义，通过 UnoCSS 输出语义变量：缩略图 `4px`（曲目行、播放栏）、独立预览 `8px`（曲目编辑器标题和封面变更预览）、卡片 `12px`（专辑列表默认值和详情更多专辑）、大幅展示 `16px`（专辑详情主封面与全屏封面）。这些是用途角色，不按每张图片的尺寸临时生成半径；CD 圆盘、档案书脊和启动实体卡片保留各自的物理形状。

曲库封面分组与专辑列表的圆角偏好继续独立生效：默认分别为 `8px` / `12px`，保留关闭圆角与 `4–24px` 调整，不扩展为全局封面开关。专辑卡片的封面、播放裁切层和外扩框继续跟随列表偏好；外扩 `3px` 时半径同步增加 `3px`。元数据封面选择卡片为 `12px` 外壳、`8px` padding、`1px` 边框，图片保持顶部对齐并按内缩推导为 `3px`；独立变更预览不受该容器规则影响。播放栏图片和悬停层由外壳裁切，避免内层再继承相同半径形成重复裁切。封面转场读取来源和目标的实际圆角，覆盖自定义、直角和不同展示角色。

播放栏主体随对应任务逐步迁移。允许有用途依据的例外；改变尺寸、主题、缩放或开合动画时，检查实际轮廓、内容裁切和高亮形状。视觉验收与源码几何检查分别记录。

参考：[Apple Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)、[ConcentricRectangle](https://developer.apple.com/documentation/swiftui/concentricrectangle)、[RoundedCornerStyle](https://developer.apple.com/documentation/swiftui/roundedcornerstyle)。

## 通用文字规格

新增或修改普通界面文字时，优先使用 `src/renderer/app/styles/typography.css` 的语义字号与配套行高。模板可使用 `.auralis-type-*` 类，组件 CSS 可引用 `--auralis-type-*-size` 与 `--auralis-type-*-line-height`。

| 角色      | 用途                     | 字号 / 默认行高 |
| --------- | ------------------------ | --------------- |
| `caption` | 辅助提示、说明、计数     | 12px / 18px     |
| `control` | 菜单、标签、输入框、按钮 | 14px / 20px     |
| `body`    | 正文、主要内容           | 16px / 24px     |
| `section` | 弹窗标题、区块标题       | 18px / 26px     |
| `page`    | 页面标题                 | 24px / 32px     |

字号和行高成对使用；字体沿用现有字体角色，字重按信息层级选择，颜色使用对应语义色。图标不作为文字字号角色，现有尺寸规则继续适用。

曲目行、歌词、CD 浏览、声迹等专用排版保留各自规格。新增例外时，在对应组件或规格文件中说明用途；涉及固定行高或虚拟滚动时，同步核对实际几何与估算指标。既有普通页面随相关任务逐步迁移。

唱片室使用独立的 `--cd-type-*` 字号与行高角色，集中定义在 `cdTypography.css`；角色、几何例外和扩展规则见[唱片室语义字号体系](../topics/albums/TECHDOC-cd-room-semantic-typography-2026-10-04.md)。

曲库虚拟列表的 CSS 实际几何必须与 virtualizer 使用的估算高度一致；相关指标集中在 src/renderer/features/library/constants/libraryLayoutMetrics.ts。

细线粗细或缩放问题结合原始截图、运行时 `devicePixelRatio` 和实际坐标排查，并通过实际渲染验证非整数缩放效果。绘制方案与检查方法参考[封面视图分割线与设备像素取整](../topics/library/TECHDOC-cover-track-divider-pixel-snapping-2026-09-28.md)。
