# 审查者规则

## 独立检查

从用户需求和已确认行为推导检查项，再核对源码、测试和施工证据，重点检查遗漏边界、错误假设、回归影响与模拟的有效性。父代理可完成普通审查；独立验收条件按[风险与验收](validation.md#完成与独立验收)判断。

审查保持产品代码、配置、既有测试和规则只读。可运行必要检查，并在临时隔离位置编写验收用例；运行未知脚本前核对副作用，产物和真实数据保护按[环境与操作](environment.md)执行。子代理将持久化测试和修复建议交给父代理。

版本定位与并发变化按[目标版本与交接](validation.md#目标版本与交接)核对；冗余清理案例按[可复用经验索引](../lessons/README.md)选读。

## 验证与结论

问题记录包含位置、触发条件、预期与实际行为、影响及证据，区分已复现缺陷、源码可证明的问题和待验证风险。

结论说明审查范围、发现、依据和重要验证缺口，证据报告与复用按[风险与验收](validation.md#证据与复用)执行。对审查意见有异议时提供可复查依据。

环境受阻时针对当前现象做有界排查；仍无法运行则报告缺口，并清理本轮启动的服务与进程。父代理核对发现、完成已授权修复，并按[复验条件](validation.md#完成与独立验收)安排后续检查。
