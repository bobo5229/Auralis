# 风险与验收

按失败后果、可恢复性和人工发现难度选择最小充分验证。父代理负责最终交付，施工者完成必要自检；需要独立验收时，由未参与目标代码施工的只读审查子代理执行。

| 任务类型                         | 默认流程                                      |
| -------------------------------- | --------------------------------------------- |
| 文档、文案等低风险修改           | 实施 → 差异复查 → 交付                        |
| 普通功能、局部缺陷修复           | 实施 → 必要检查 → 修复与复验 → 交付           |
| 高风险任务或用户明确要求独立验收 | 实施及自检 → 独立验收 → 按修复影响复验 → 交付 |

按行为影响选择定向测试、类型与语言键检查、Lint、格式、构建或实际运行。跨模块影响、范围难以确定或发布要求需要全量回归时，说明原因。选择命令前核对 package.json 中的脚本与 pre/post 钩子，复用组合脚本已通过的检查；会写入同一缓存、构建输出或改变同一原生环境的检查串行执行，其余独立检查可并行。

## 目标版本与交接

普通验证利用当前会话和工具结果定位改动。跨会话、实际并发、高风险验收、发布或长期复用证据时，记录基准提交号与相关差异，仍难定位时补充内容哈希；未提交内容包含在差异中。

委派验收期间，本任务暂停修改目标与相关依赖。子代理在开跑前和回报前核对目标变化，父代理收到报告后复查相关工作区差异、暂存区及未跟踪文件。外部修改影响验收时复验对应范围，持续并发妨碍验收时使用适合的隔离副本或 worktree。

同一目标的修复与复验串行进行。自检发现问题后完成已授权修复并复验；独立验收发现问题后由父代理核对、修复，再按[复验条件](#完成与独立验收)安排检查，优先复用适任审查子代理。

## 缺陷回归与界面证据

测试断言需求行为与外部结果，模拟外部依赖时保留待验证逻辑。失败先定位原因，因需求变化调整断言时记录依据。保留有效测试与断言，禁止通过跳过测试或替换关键逻辑制造通过结果。

缺陷修复优先复现用户报告的操作路径，验证修复后的外部结果，并按风险补查相邻边界。菜单问题检查真实组件的渲染与事件路径，动态菜单覆盖受影响的键盘导航；布局、裁切、细线和吸顶问题使用实际画面，必要时测量坐标、尺寸与缩放条件。

隔离验证说明保留的真实组件或模块、模拟依赖及覆盖范围；状态和几何计算测试可补充界面证据。

## 原型与音频效果

技术能力不确定、集成成本高或方案差异明显时，用小型可运行原型验证核心差异。现有界面的颜色、间距、布局和动效直接在真实界面迭代。比较时保持关键条件一致；交付原型提供启动方式，确认目标所需的素材、出声与交互。

音乐驱动效果分别检查算法或时序与实际听感，按风险选择代表性曲目或片段，覆盖相关暂停、跳转和切曲。记录曲目表现差异；已有用户试听反馈一并作为方案依据。

## 短时动效与性能

卡顿诊断区分冷启动、首次进入和再次进入，测量问题阶段，结合单帧耗时、长任务、资源准备、布局和绘制定位瓶颈。

性能对照采用实际调用路径及可比输入、环境。分别记录算法微基准与页面运行的测量范围和结果。

## 完成与独立验收

阶段任务按约定完成实现、差异复查和必要自检，交接结果与待验证项；父代理承担剩余验证和最终交付。用户明确禁止检查时遵从限定，委派权限按[项目入口](../../AGENTS.md)执行。

用户明确要求独立验收，或改动可能造成难以恢复的数据损失、安全越界、难以通过局部检查发现的关键行为回归时，必须独立验收。典型情形包括数据库迁移、音乐文件写回或删除策略、IPC 信任与权限边界，以及复杂播放并发或窗口生命周期。文档和样式同样按实际行为影响判断风险。

独立验收从需求推导检查项，重点检查关键风险与证据缺口，复用有效自检结果，并独立复现必要的关键行为。

独立验收后的修复涉及行为缺陷、原高风险行为、验收标准或结论变化时，须独立复验；保持行为、契约和结论不变的排版、拼写、注释等编辑性修正由父代理复查。用户要求全部修复独立复验时遵从指定。

需求已覆盖、必要检查通过且范围内问题已处理后交付。必需的独立验收或复验尚未完成时，标记“待独立验收”或“待独立复验”。父代理核对最终版本、失败与跳过项及验证缺口，形成结论。

## 证据与复用

交付或阶段交接说明改动、实际检查与结果、重要未验证项。运行检查记录命令或复现步骤和退出结果，区分自检与独立验收来源，详略按风险确定。

相关代码、测试、配置、依赖和运行环境仍适用时复用已有结果。内容变化、证据缺失或存疑、新增场景，以及关键行为需要独立复现时，补做对应检查。跨会话、高风险或发布证据补充覆盖范围、环境信息，并按[目标版本与交接](#目标版本与交接)定位代码。

源码推断、模拟测试、隔离组件运行、完整应用、视觉与性能结论分别对应实际证据。报告载体按[施工提示词写法](handoff-prompts.md)选择。
