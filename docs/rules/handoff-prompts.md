# 施工提示词写法

为 6LunaMax 编写施工提示词时，同时读取[6LunaMax 施工提示词撰写规则](6lunamax-construction-prompts.md)。默认使用普通模式；机械迁移、精确复现或需锁定实现时使用严格模式。

提示词简要说明目标、可观察的验收效果和完成任务所需的背景。补充关键文件、现有行为或范围边界时，只写会影响结果的内容；已确定的设计选择写明确，其他实现判断留给执行者。

## 按需交接

需要委派任务或跨会话继续工作时，提供简短交接；验证流程与完成状态统一按[风险与验收](validation.md)执行。

模型、思考强度和代理数量按[子代理派遣与额度](agent-dispatch.md)选择，交接使用需求、代码定位和已有证据的简短摘要。

施工提示词明确目标、授权范围、关键入口、必须保留的行为和完成条件。委派或跨会话时，说明接收者承担最终交付还是阶段任务、必要检查由谁执行，以及阶段停止点和交接对象。已确定的接口与关键方案写明确，局部可逆的实现细节由执行者判断；完成状态按[完成与独立验收](validation.md#完成与独立验收)区分。

审查提示词给出目标、范围、已有结果和待检查项；版本信息按下段记录。独立验收者按需求自行推导检查项，再核对实现与施工报告；保持产品代码、配置、既有测试和规则只读，持久化测试与修复建议交给父代理。

同一会话中的普通交接使用一条简短消息即可；需要持续修订、复用或跨会话传递较完整方案时，再保存文档，不按字符数或行数设门槛。用户指定载体或路径时遵从指定。版本定位、冻结目标和修复复验顺序按[目标版本与交接](validation.md#目标版本与交接)执行。

报告内容与证据复用按[证据与复用](validation.md#证据与复用)执行；环境受阻时按[审查者规则](review.md)处理。
