# 施工提示词写法

交接说明目标、授权范围、关键入口、保留行为、已确定的方案和完成条件。局部可逆的实现由执行者判断。

需要精确复现、固定算法结果或保证迁移顺序时，只对相关部分写清必须遵守的决策、起始条件和验收结果。执行者核对起始条件，自行适配代码位置变化和局部实现。

## 范围与职责

文件列表默认表示关键入口，授权功能内的调用方、测试和引用等必要配套修改一并完成。用户明确锁定文件或并行施工需要划分所有权时，标明封闭清单及原因，调整边界前协调。

明确接收者承担最终交付还是阶段任务，以及必要检查的执行者、阶段停止点和交接对象。模型与代理数量按[子代理派遣与额度](agent-dispatch.md)选择。

审查交接给出需求、范围、已有证据和待检查项，具体审查行为按[审查者规则](review.md)执行。

## 载体与证据

普通交接使用简短消息；需持续修订、复用或跨会话传递完整方案时保存文档。用户指定载体或路径时遵从指定。

版本定位和复验安排按[目标版本与交接](validation.md#目标版本与交接)，检查结果与缺口按[证据与复用](validation.md#证据与复用)报告，环境受阻时按[审查者规则](review.md)处理。
