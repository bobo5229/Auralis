# 施工提示词写法

为 6LunaMax 编写施工提示词时，同时读取[6LunaMax 施工提示词撰写规则](6lunamax-construction-prompts.md)：撰写者先确定实现决策，再交付细到可以直接执行的步骤；本页关于将实现判断交给执行者的默认方式不适用于该类交接。

提示词简要说明目标、可观察的验收效果和完成任务所需的背景。补充关键文件、现有行为或范围边界时，只写会影响结果的内容；已确定的设计选择写明确，其他实现判断留给执行者。

## 按需交接

普通施工任务直接要求完成实现、差异复查和交付，说明未测试，无需额外编写交接提示词。跨会话继续工作或按[风险与验收](validation.md)进入独立验收时，再提供交接信息。

施工提示词明确目标、授权范围、需求入口和完成条件，将实现判断留给执行者，并明确施工阶段不执行测试或验收。施工交付标记“实现完成，未测试”；需要独立验收时补充待验收状态。

审查提示词明确默认只读、负责测试与验收、同一需求入口和稳定的验收目标，要求先独立推导检查项，再核对实现与施工证据；复用有效结果并补充必要验证。提供施工交付报告，但不能仅以报告中的检查项定义验收范围。

交接包含目标、改动范围、可定位的代码状态和待验证项；已有验证结果时注明来源与适用范围，不要求施工者补跑。优先使用交付消息。独立审查期间暂停修改同一验收目标，修复与复验串行进行；发现相关并发变更时重新确认受影响证据。已获修复授权可按角色规则接管，复验要求仍按风险判断。
