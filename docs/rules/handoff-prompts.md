# 施工提示词写法

为 6LunaMax 编写施工提示词时，同时读取[6LunaMax 施工提示词撰写规则](6lunamax-construction-prompts.md)。默认使用普通模式；机械迁移、精确复现或需锁定实现时使用严格模式。

提示词说明目标、可观察的验收效果及影响执行的背景。写明关键文件、现有行为、范围边界和已确定的设计选择，将局部实现判断留给执行者。

## 按需交接

委派任务或跨会话继续工作时提供简短交接，验证流程与完成状态按[风险与验收](validation.md)执行。

模型、思考强度和代理数量按[子代理派遣与额度](agent-dispatch.md)选择。

施工提示词写明目标、授权范围、关键入口、保留行为、已确定的接口与方案，以及完成条件。交接时明确接收者承担最终交付还是阶段任务，说明必要检查的执行者、阶段停止点和交接对象。局部可逆的实现细节由执行者判断。

审查提示词给出目标、范围、已有结果和待检查项。独立验收者按需求推导检查项，再核对实现与施工报告；保持产品代码、配置、既有测试和规则只读，将持久化测试与修复建议交给父代理。

同一会话中的普通交接使用简短消息；需持续修订、复用或跨会话传递完整方案时保存文档。按用途选择载体，用户指定载体或路径时遵从指定。版本定位、目标冻结和修复复验顺序按[目标版本与交接](validation.md#目标版本与交接)执行。

报告内容与已有结果的复用按[证据与复用](validation.md#证据与复用)执行，环境受阻时按[审查者规则](review.md)处理。
