# Phase 13 基线

**记录日期**：2026-08-13
**状态**：工程审查通过，待人工验收
**目标范围**：仅专辑详情路由 `name: 'album-detail'`

## 1. 工作树与协作约束

Phase 13 由多个 worker 并行实现。现有未提交改动属于各工作包，不回退、不覆盖其他 worker 的页面、
样式或共享状态修改。本基线只记录详情页手稿化的边界、风险和待验收项，不宣称整仓测试已完成。

## 2. 必须保留的现代模式行为

- 返回专辑目录；
- 整张播放和专辑内随机播放；
- 曲目按碟号、曲序排序，多碟时显示分组；
- 单击选择、双击播放、正在播放与搜索定位高亮；
- 封面、发行日期、流派、版权、曲目数和总时长展示；
- 播放次数与估算收听时长统计；
- 同艺人相关专辑排序、横向滚动与跳转；
- 动态极光、pointer tilt 和 `prefers-reduced-motion` 处理；
- 相关专辑图片的 `loading='lazy'` 与 `decoding='async'`。

手稿模式可以改变视觉编排，但不得改变上述产品语义。动态极光和 pointer tilt 在手稿模式停用，在
modern 模式保持现状。

## 3. 明确排除

Phase 13 不覆盖应用窗口外壳、Sidebar、Now Playing、Playbar、Miniplayer、desktop lyrics、fullscreen
playback，也不扩大 LibraryPage 或 AlbumsPage 的既有视觉作用域。

## 4. identity 与国际化基线

详情页以专辑艺人和专辑标题组合定位数据。内部缺失值 `Unknown Artist`、`Unknown Album` 继续用于分组、
比较和路由查询，不进行本地化替换。用户可见文案改由 `albums.detail.*` 提供，简体、繁体和英文必须
保持完全相同的叶子 key 集合。

## 5. 状态基线

当前阶段要求明确区分四类页面状态：首次 loading、加载 error、加载完成后的 not-found、正常详情。
错误态提供 retry，未找到态提供 return to albums。异步刷新不得让已有详情闪烁为未找到，也不得改变
播放队列或当前曲目。

## 6. 风险与约束

1. 仅按路径前缀判断会把非目标页面纳入手稿风格；必须使用 `route.name === 'album-detail'`。
2. 在页面内新建视觉偏好会形成第二状态源；必须复用共享 `useVisualStyle`。
3. 详情 CSS 未加根作用域会污染专辑目录或播放器外壳；由静态脚本检查每条规则。
4. 翻译内部未知值会破坏分组和路由 identity；仅本地化显示层。
5. 手稿模式若继续运行极光取色和指针跟踪，会产生不可见计算与残留 transform；切换时必须停用和清理。
6. 状态改造可能把请求期间的空数组误判为 not-found；需要显式状态机或等价的互斥条件。
7. 详情页长标题、多碟和相关专辑横向区可能在窄宽度或高缩放下溢出。

## 7. 待主线程整合后的验收矩阵

| 维度     | 数据或环境                         | 通过标准                                   |
| -------- | ---------------------------------- | ------------------------------------------ |
| 页面状态 | loading、error、not-found、success | 文案与动作对应，状态互斥且无闪烁           |
| 标题     | 长专辑名、长艺人名、中英混排       | 不遮挡操作，层级清晰，无水平页面溢出       |
| 封面     | 正常封面、缺封面                   | 比例稳定，占位明确，不发生布局跳动         |
| 曲碟     | 单碟、多碟、未知曲名               | 顺序正确，碟片标题只在多碟需要时出现       |
| 时长     | 0、分钟级、小时级                  | 三语格式正确，缺失数据不产生 `NaN`         |
| 统计     | 0 次、仅次数、分钟级、小时级       | 无记录时不伪造统计，其余格式与数值正确     |
| 相关专辑 | 0、1、多张、缺封面                 | 空区不渲染；滚动、打开、图片加载属性保留   |
| 宽度     | 900、1279、1280、1600 像素         | 内容不遮挡，断点两侧布局稳定               |
| 缩放     | Windows 100%、125%、150%           | 文本与按钮可读可操作，无裁切               |
| 风格切换 | modern ↔ manuscript                | 行为状态保留，极光与 tilt 启停正确，无残留 |
| 排除区域 | shell 与全部播放器表面             | 视觉、布局、材质和交互保持原样             |
