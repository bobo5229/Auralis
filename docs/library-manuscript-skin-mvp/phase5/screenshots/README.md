# Phase 5 验收截图

本目录受版本控制（见仓库根 `.gitignore` 对 `docs/library-manuscript-skin-mvp/**` 的例外）。

## 必交文件

在主窗口 `/` 全部歌曲页、真实曲库下截取并按下列文件名提交：

| 文件名                 | 维度                                 |
| ---------------------- | ------------------------------------ |
| `flat-modern.png`      | 平铺视图 · modern                    |
| `flat-manuscript.png`  | 平铺视图 · manuscript                |
| `cover-modern.png`     | 封面分组 · modern                    |
| `cover-manuscript.png` | 封面分组 · manuscript                |
| `window-below-xl.png`  | 窗口宽度 `< xl`（Now Playing 隐藏）  |
| `window-xl.png`        | 窗口宽度 `>= xl`（Now Playing 可见） |

建议在 manuscript 截图中包含：当前播放行暗红竖条、搜索框与「流光 / 手稿」切换控件。

## 对照路由（不纳入本目录也可）

- 智能歌单 / 普通歌单：应**无**纸张画布与手稿 token（防泄漏手测）。
- Sidebar / Playbar / Miniplayer：保持现代视觉。
