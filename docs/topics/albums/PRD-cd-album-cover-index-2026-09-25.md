# PRD：CD 封面检索页

日期：2026-09-25  
状态：产品方向已确认，待实现与视觉确认。  
配套实现说明：[TECHDOC](./TECHDOC-cd-album-cover-index-2026-09-25.md)。

## 目标

CD 浏览页逐张切换光盘，面对约 952 张专辑时难以快速抵达远处的作品。新增独立的封面检索页，让用户先通过专辑艺术家定位，再凭封面辨认专辑，点击后直接进入该专辑的光盘聚焦状态。

封面是检索的主要线索。页面保留专辑名称和发行日期，帮助用户确认作品及其在艺术家作品序列中的位置。

## 页面结构

- 顶部居中放置“光盘浏览 / 封面检索”视图切换入口，仅在两个非聚焦页面显示。
- 检索页以专辑艺术家为一级分组。每组显示艺术家名称，以及按发行日期从旧到新排列的专辑卡片。
- 每张卡片直接展示封面、专辑名称和发行日期；名称与日期属于同一层级的辅助信息，始终可见。
- 提供 A–Z 字母索引。点击字母跳到该字母的第一位艺术家；页面也支持连续滚动浏览。
- 不设置文字搜索框。用户通过字母索引、艺术家分组与封面视觉完成检索。
- 页面沿用 CD 浏览区域的浅色 / 深色配色及切换偏好；封面在两种背景下都保持清晰。

## 排序与呈现

专辑艺术家按 A–Z 排列。中文艺术家用姓名拼音参与排序和字母归类，界面保留其原始中文名称。排序不改变元数据，也不把专辑归到曲目艺术家名下。

同一专辑艺术家的专辑按发行日期从旧到新排列。同日作品按专辑名称稳定排序；缺少有效发行日期的作品排在该艺术家组末尾，卡片日期位置显示统一的缺省符号。没有可用艺术家名称的专辑归入末尾的“#”组。

卡片尺寸随窗口宽度调整，以能直接辨认封面为基准。初版沿用现有专辑网格约 180–210px 的封面尺度，再通过实际窗口视觉确认间距与列数。

## 进入与返回

点击专辑卡片后，页面切换到 CD 浏览页，并让所选光盘已处于居中聚焦位置淡入。跳过普通浏览入口的开场动画、抖动和横向平移；进入聚焦本身不触发播放。

从检索页进入聚焦时，左上角返回回到检索页，恢复离开前的滚动位置。刚才点击的专辑卡片出现一次阴影高亮，随后在约 1 秒内渐隐，帮助视线找回位置。键盘 Escape 与左上角返回遵循同一返回路径。

从普通光盘浏览进入聚焦时，左上角返回仍回到光盘浏览状态。聚焦状态顶部居中继续显示现有的“CD 质感 / 黑胶质感”切换；视图切换入口在聚焦状态隐藏。

## 验收场景

1. 在约 952 张专辑的曲库中，能通过 A–Z 索引迅速到达目标艺术家，再通过封面找到专辑；滚动时艺术家分组和卡片顺序保持稳定。
2. 中文艺术家按拼音参与字母排序，显示名称仍为中文；同一艺术家的专辑按发布日期从旧到新排列。
3. 点击卡片直接看到目标光盘居中淡入并进入聚焦，没有队列平移或开场抖动，也没有自动开始播放。
4. 从检索页返回时恢复原滚动位置，原卡片的阴影高亮在约 1 秒内消退；从普通光盘浏览进入聚焦时保留原返回行为。
5. 浅色与深色模式下，封面、艺术家标题、专辑名、日期和字母索引均清晰可辨；聚焦状态保留质感切换。
