# TECHDOC：CD 封面检索页

日期：2026-09-25  
状态：实现方案，待施工。  
产品定义：[PRD](./PRD-cd-album-cover-index-2026-09-25.md)。

## 当前实现基线

- `src/renderer/app/router/index.ts` 将 CD 浏览页映射到 `/albums/cd`；`routeComponentLoaders.ts` 为它提供懒加载入口。
- `CdAlbumsPage.vue` 使用 `auralis.library.getTracks()` 与 `groupAlbums()` 获取专辑；路由的 `artist`、`title` 查询参数用于定位专辑。初次载入命中目标时，现有 `controller.setFocused(true, 'fade')` 已能使居中光盘淡入。
- `albumGrouping.ts` 按 `albumArtist + title` 生成专辑，`albumIdentity.ts` 提供身份键。`AlbumSummary` 已包含封面缓存键、名称和发行日期。
- `App.vue` 仅对 `cd-albums` 启用独立 CD 画布、隐藏 Sidebar / PlayerBar 并停用壳层流光背景；新页面需要纳入同一画布区域。
- `useCdCanvasTheme.ts` 保存 CD 画布浅色 / 深色偏好。现有 `AlbumsPage.vue` 已使用 `@tanstack/vue-virtual` 渲染大量封面行，可复用其虚拟行思路。

## 页面与路由

新增一个封面检索页面组件，建议路由名 `cd-album-index`、路径 `/albums/cd/index`。在 `routeComponentLoaders.ts` 增加懒加载，并让 `App.vue` 将两条 CD 路由统一视为 CD 画布页面：相同的窗口背景、浅深色偏好和壳层显隐。

非聚焦状态的 CD 浏览页与检索页顶部居中使用同一组“光盘浏览 / 封面检索”文字入口，当前视图沿用页面已有的文字下划线语言。CD 聚焦时继续显示现有质感切换，并隐藏视图入口。视图切换只负责导航，不改变播放队列、当前曲目或光盘质感。

检索页直接使用现有 `library.getTracks()` 结果和 `groupAlbums()`。读取与曲库变更订阅可沿用 `useAlbumCatalog` 的模式；无需数据库迁移或新的 IPC。封面地址继续通过 `getArtworkUrl(artworkCacheKey)` 获取，图片只在即将进入视口时加载。

## 分组和排序

从 `AlbumSummary[]` 构造纯计算的艺术家分组，使用 `albumArtist` 原值作为分组身份，保留页面显示名称。为排序单独生成拼音键：汉字转换为无声调拼音，拉丁字母统一大小写；中文按转换后的拼音进入 A–Z 字母桶。拼音转换需要支持多音字词组，采用小型现成转换库或项目已有能力，不把浏览器的 `Intl.Collator('zh-Hans-u-co-pinyin')` 当作首字母转换器：它能比较顺序，但不能提供字母索引。数字、符号及无法转写的开头归入末尾“#”。同排序键再比较原始艺术家名称与身份键，保证结果稳定。

每组内按可解析的发行日期升序排序；同日按专辑名称及身份键排序；无有效日期排在最后。现有 `sortAlbumsByYearThenTitle()` 只比较年份，不满足本页的完整日期排序，新增局部排序函数即可。现有 `Unknown Artist` 占位艺术家归入末尾“#”组。多值或合辑名称遵循现有 `resolveAlbumArtist()` 结果，不另行拆分或推断归属。

把分组标题和其后的封面网格行拍平成有类型的行模型，记录每个字母首行的索引。字母索引调用虚拟列表的 `scrollToIndex()` 跳转；目标字母没有内容时呈禁用状态。采用 `@tanstack/vue-virtual` 只渲染可见行及少量缓冲行，封面卡片保持稳定 key。窗口尺寸变化时重算列数、行高和字母锚点，避免长列表中点击索引后落到错误分组。

## 导航与返回定位

点击专辑卡片时，先记录卡片的 `album.key` 和列表滚动位置，再导航到 `cd-albums`，携带现有的 `artist`、`title` 参数及明确的检索页来源标记。`CdAlbumsPage.vue` 继续使用现有目标定位与淡入分支，不增加第二套聚焦动画。

CD 页的 `back()` 根据来源决定路径：来自检索页时路由返回 `cd-album-index`；普通进入时继续执行 `controller.setFocused(false)`。Escape 复用同一逻辑。来源只影响返回，不参与专辑身份匹配。

检索页重新出现后，先用当前布局恢复滚动位置，再根据记录的身份键找到卡片。如果尺寸变化或曲库刷新使旧位置失效，以目标卡片所在行重新定位。卡片完成定位后触发一次阴影高亮，并在约 1 秒内渐隐；状态在动画结束后清除，重新进入页面不重复播放。遵循系统减少动态设置：保留短暂静态定位提示，取消渐隐动画。

## 视觉和状态

新页面使用 `useCdCanvasTheme()` 的同一偏好；浅色与深色画布背景分别沿用现有 CD 页面值。卡片保持封面原色，阴影只在悬停与返回定位时提供轻微层次，不在深色模式中制造大片灰色光晕。艺术家标题建立一级层级，专辑名称与日期紧随各自封面。日期缺失显示统一短横线，封面缺失沿用现有专辑卡片的占位方式。

首次加载、空曲库与读取失败沿用 CD 页面既有的页面状态语义。页面不增加文字搜索、扫描逻辑或播放控制。
