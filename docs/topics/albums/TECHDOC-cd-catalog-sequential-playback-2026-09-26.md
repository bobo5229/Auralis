# TECHDOC：CD 浏览全库顺序播放

日期：2026-09-26  
状态：实现方案，待施工。

## 目标行为

CD 浏览页增加“全库顺序”选项，并将它设为页面默认选中项。用户点击某张唱片中的曲目后，播放器从该曲目开始，播完当前专辑的剩余曲目，再按 CD 浏览页左右切换唱片的顺序播放后续专辑。最后一张专辑的最后一首结束后停止。

CD 页面保留现有三种选项：“专辑循环”播完当前专辑后从头循环；“随机循环”在当前专辑内随机循环；“顺序播放”播完当前专辑后停止。“全库顺序”与“顺序播放”共用播放器已有的 `sequential` 模式，差别由播放队列的范围决定。

进入 CD 页面只初始化按钮选中值，不改变正在播放的曲目、队列或播放器模式。点击 CD 曲目才按所选模式开始播放。CD 页面已发起的播放过程中切换选项，当前曲目和进度保持不变，后续曲目立即按新选项接续。自动跨专辑时，浏览画面与聚焦画面都停留在用户正在查看的唱片。

离开 CD 页面后，播放沿用已经建立的队列和模式。普通播放栏继续使用现有模式菜单；由“全库顺序”发起的播放在普通播放栏显示已有的“顺序播放”。

## 当前实现基线

- `CdAlbumsPage.vue` 的 `albumInfo` 是 CD 浏览的唱片序列。它直接采用 `cdAlbumCatalogSession.load()` 返回的专辑顺序，唱片舞台也接收同一数组。封面检索页另有艺术家和发行日期排序，不能拿来决定本模式的接续次序。
- `albumGrouping.ts` 的 `selectAlbumTracks()` 按碟号、曲号和标题排列单张专辑的曲目。构造跨专辑队列时沿用 `albumInfo` 中已经排好的 `tracks`。
- `CdAlbumsPage.vue` 当前用局部 `cdMode: PlaybackMode` 保存三种选项；`playCdTrack()` 只向 `playTrackFromQueue()` 传入当前专辑曲目；`cycleMode()` 在页面持有当前队列时调用 `setPlaybackMode()`。
- 播放控制器的 `sequential` 按 `state.queue` 向后播放，在队列末尾自然结束时停止。`AlbumsPage.vue` 已用“当前及后续专辑曲目组成队列”的方式实现普通播放栏的顺序播放。
- `playTrackFromQueue()` 会清空音频运行时并重新启动曲目。播放中切换模式需要保留当前音频会话，不能借它重建队列。

## 模式和队列

在 CD feature 内定义独立的选项类型，例如 `CdPlaybackMode = 'catalog-sequential' | 'repeat-all' | 'shuffle' | 'sequential'`。默认值为 `catalog-sequential`。播放器公共 `PlaybackMode` 保持现有取值；`catalog-sequential` 在调用播放器时映射为 `sequential`。模式按钮增加对应文案与图标，四项按明确的顺序循环，避免把 CD 专用标识传入普通播放栏或播放器模式菜单。

从 `albumInfo` 直接构造两类队列：

1. “全库顺序”：找到起始曲目所属专辑，取该专辑及后续所有专辑，按数组顺序串联各自的 `tracks`。队列包含起始专辑的全部曲目，播放器的 `currentIndex` 指向用户点击的曲目，因此自然播放从该曲目继续。
2. 其余三种选项：队列只含起始曲目所属专辑的 `tracks`。“随机循环”继续把该专辑设为 `shufflePool`，并启用现有的完整轮次逻辑。

以 `album.key` 和 `track.id` 定位专辑与曲目，不根据当前聚焦唱片推断正在播放的专辑。用户浏览到另一张唱片时，播放中的模式切换仍以**实际当前曲目**为锚点。专辑目录为空、当前曲目不在目录中，或当前队列已由其他页面接管时，按钮只更新 CD 页的待选值；下次点击 CD 曲目时再应用。

## 播放中切换

在共享播放控制器增加一个受约束的“为当前曲目更换队列与模式”入口，由 CD 页面在持有当前播放队列时调用。调用时携带预期的当前曲目 ID 和旧队列曲目 ID；控制器验证播放器仍处于该上下文，且当前曲目存在于新队列，然后一次性更新 `state.queue`、`state.currentIndex`、`state.playbackMode` 和导航会话的随机范围。清理旧队列留下的待播插入项与随机轮次；按照新模式建立专辑内随机范围。CD 页面同步更新用于判断队列归属的曲目 ID，防止跨专辑队列被误判为外部接管。

更换队列时保持 `currentTrack`、`currentTrackId`、`currentTime`、播放/暂停状态、音频运行时和有效播放统计会话。取消按旧队列预排的无缝下一首，再按新队列重新预排；已开始的曲目不中断。切回“顺序播放”“专辑循环”或“随机循环”时，队列恢复为实际当前曲目所属专辑，模式与随机范围同步更新。

模式选择只在 CD 页面持有当前播放队列时驱动上述更换。进入页面、左右切换唱片、进入或退出聚焦状态、以及离开 CD 页面，都不触发队列重建。普通页面随后主动选择新曲目或修改播放模式时，由共享播放器的现有行为接管。

队列在点击曲目或切换模式时根据当前 CD 专辑快照生成。目录刷新后的排序在下一次 CD 播放操作中生效，已经建立的播放队列保持连续。

## 定向验收

- 进入 CD 页面时按钮默认显示“全库顺序”；已在其他页面播放的曲目、队列和模式保持原值。
- 在中间一张专辑点击中途曲目，确认先播完本专辑，再按左右切盘顺序进入下一张；最后一张结束后停止。单曲专辑也按相同规则接续。
- 分别检查原有三种选项仍以单张专辑为范围；“顺序播放”在该专辑末尾停止，“专辑循环”返回该专辑首曲，“随机循环”不跳到其他专辑。
- CD 发起的播放中切换“全库顺序”与其他选项，确认当前声音、进度和播放统计计时连续，下一首立即遵循新队列；无缝预排不会按旧队列跳转。
- 播放跨到下一张专辑时，浏览和聚焦画面不自动切盘。退出 CD 后普通播放栏显示已有的“顺序播放”，播放继续使用同一跨专辑队列。
- 为队列构造、播放中更换队列、末尾停止、专辑内随机范围和外部队列接管添加定向测试；页面行为以实际播放检查。
