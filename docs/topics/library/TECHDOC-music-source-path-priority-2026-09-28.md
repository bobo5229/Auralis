## 1. 目标

将「设置 → 音乐资料库 → 音乐来源」改为路径优先布局。完整文件夹路径占据卡片上部，路径下方独立显示资料库摘要和操作。用户在深层目录、窄窗口、键盘操作与触屏场景下都能直接读取完整位置。

本次只调整音乐来源卡片的呈现与交互细节，继续使用当前 `MusicLibrarySettings.vue` 的资料库状态、扫描事件和类型化 `auralis.library` API。扫描算法、根目录选择语义和持久化方式保持现有实现。

设计参照为已确认的三方案 Demo 中的 B「路径优先」，文件位于 `C:/Users/BoBo/.codex/visualizations/2026/09/27/01a0e191-eadf-7b60-9619-cc32fa00a02a/music-source-layouts.html`。该 Demo 的路径、数量和进度为固定示例；正式页面只显示真实状态。

## 2. 修改前布局（历史记录）

`src/renderer/features/settings/components/MusicLibrarySettings.vue` 中，`.library-source-row` 将标题、路径、摘要与两个操作按钮放在同一横排。`.library-source-path` 使用 `white-space: nowrap`、`text-overflow: ellipsis` 截断路径，完整内容依靠 `v-tooltip.overflow` 展示。这种布局让长路径的辨认依赖悬停；窄宽度下信息区也与按钮争夺空间。

组件当前取 `roots[0]` 作为 `activeRoot`，按 `LibraryScanStatus` 和 `LibraryScanProgress` 显示扫描状态；选目录、开始扫描、取消扫描分别调用现有 `auralis.library` 方法。扫描进度和操作错误已经有独立的卡片内区域。新布局复用这些数据与状态，不建立第二套来源。

## 3. 目标布局

```text
┌──────────────────────────────────────────────────────┐
│ 音乐文件夹                                           │
│ D:\Music\Archive\Classical\Live Recordings\Albums │
│ 路径按可用宽度自动换行，始终可选择复制               │
├──────────────────────────────────────────────────────┤
│ 文件数 · 上次扫描时间                  [更改] [重新扫描] │
├──────────────────────────────────────────────────────┤
│ 正在扫描时：现有真实进度、失败数量和取消操作         │
└──────────────────────────────────────────────────────┘
```

上图仅表示区域顺序；文件数、时间、进度和路径均由现有状态计算。正式文案沿用项目本地化资源。

- **上部**：保留「音乐文件夹」标题。路径独占下一行，使用当前设置页字体链；英文段落沿用现有英文字体。路径从左到右排版、允许任意长片段断行，不用省略号截断，也不依赖 tooltip 才能读取完整内容。
- **下部**：用卡片内部细分隔线区分摘要和操作。宽屏时摘要在左、按钮组在右；空间不足时摘要在上、按钮组在下，按钮组靠右。按钮不压缩路径，不造成页面水平溢出。
- **扫描与错误**：现有 `.library-scan-inline` 和 `.library-error-row` 保持卡片下方的独立层级。扫描中的取消操作仍归扫描状态区管理；不将 Demo 的固定进度或占位数字接入正式页面。
- **空状态**：上部显示当前「尚未选择音乐文件夹」文案；下部显示选择指引与「选择文件夹」按钮，不展示无法执行的扫描按钮。

## 4. 状态与操作

| 状态                   | 上部       | 下部与附加区域                                                            |
| ---------------------- | ---------- | ------------------------------------------------------------------------- |
| 未选择文件夹           | 空状态文案 | 选择指引；「选择文件夹」                                                  |
| 已选择、待首次扫描     | 完整路径   | 等待首次扫描状态；「更改」「扫描资料库」                                  |
| 已选择、扫描完成或取消 | 完整路径   | 现有文件数与上次扫描时间；「更改」「重新扫描」                            |
| 扫描中                 | 完整路径   | 摘要和禁用的「更改」；现有进度区显示已扫描/总数、失败数、百分比及「取消」 |
| 扫描失败               | 完整路径   | 现有状态摘要与可用的重新扫描操作；操作失败消息仍显示于错误区              |

扫描中的「重新扫描」不呈现；恢复非扫描状态后按当前 `scanStatus` 选择「扫描资料库」或「重新扫描」。保留 `isLoading`、`isScanning` 对重复操作的限制。选择目录取消、扫描取消和 IPC 错误沿用当前方法的结果处理，不凭视觉状态推断任务已完成。

## 5. 实施位置

主要修改 `src/renderer/features/settings/components/MusicLibrarySettings.vue`：

1. 将 `.library-source-row` 重组为上部路径区与下部摘要/操作区，保留现有响应式数据、方法及扫描进度/错误模块。
2. 将 `.library-source-path` 改为 `white-space: normal; overflow-wrap: anywhere;`，保留 `direction: ltr`、文字选取能力和 `font-family: inherit`。移除该位置依赖截断的 `v-tooltip.overflow`。
3. 为下部设置边框和响应式排列；沿用 `settings-group-card`、`settings-button`、主题变量和现有焦点样式，不复制 Demo 的独立色板。
4. 空状态按条件渲染扫描按钮；如需要新增或调整文案，在 `src/renderer/locales/zh-Hans.json` 及相应语言资源中同步维护。

结构可使用现有 class 扩展，避免新建组件或改变跨进程契约。文件路径是用户可读的内容，应在元素内以文本插值呈现，不使用 `v-html`。

## 6. 验收

- 在已选择、空状态、扫描中、扫描失败和操作错误状态下检查标题、完整路径、摘要、按钮与进度区的顺序及可用性。
- 使用含中文、空格和很长单段文件夹名的路径，在桌面宽度和窄窗口检查完整可读、可选择复制、无水平滚动；浅色与深色主题均可读。
- 用 Tab 键到达各操作，确认焦点描边、按钮禁用及扫描取消行为。选择或扫描触发组件更新后，焦点应留在仍可用的对应操作上；原按钮消失时转移到合理的后继控件。
- 通过隔离的模拟状态或测试桩验证组件行为；涉及真实曲库和音乐文件时采用只读观察，不以用户数据做破坏性验证。
- 运行与 `MusicLibrarySettings.vue` 相关的定向检查，并在 Electron 中对两种主题与窄宽度做视觉验收。只读静态检查不能替代运行和视觉结果。
