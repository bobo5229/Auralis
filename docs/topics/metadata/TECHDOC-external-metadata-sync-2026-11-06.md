# 外部元数据同步

正式应用读取本地音乐文件，不再提供单曲、整张专辑、封面或歌词编辑，不写入音频标签，也不保存 `.lrc`。在 foobar2000 等外部工具中修改文件后，Auralis 通过原有文件监听、扫描或手动刷新更新曲库和播放信息。歌词显示、增强 LRC、简繁转换与 TTML 缓存恢复继续保留。

## 历史覆盖

启动将 `track_metadata` 中仍有覆盖位或旧编辑来源的曲目加入已有 `pending_tag_recovery_refresh` 队列，仅失效这些曲目的完整元数据检查标记。文件监听服务将队列路径作为显式刷新意图交给原有串行 metadata worker；扫描也可通过失效标记重新读取。

完整文件读取结果通过任务、曲目路径与文件指纹校验后，在数据库事务中提交真实标签、解除覆盖、更新艺术家和专辑投影、删除队列项。缺失标签保持 `null`，展示回退不进入真实标签。歌词或封面局部更新不解除文本覆盖。

离线、解析失败、文件变化或事务失败保留旧覆盖及待处理项；后续启动、扫描、刷新或文件事件可重试。不新增数据库表、不提升全库解析版本、不新增恢复调度器，历史 schema 迁移继续保留。

## 文件与播放边界

旧版中断写入的备份恢复独立保留：仅补回缺失原路径，不覆盖已有原文件，不把旧数据库标签写回音乐。恢复后仍走同一个刷新队列。

播放文件协调器只管理读租约，保留路径身份校验、取消和释放。mpv、FFmpeg、预载、无缝衔接、柔和转场及频谱继续使用；转场音源与频谱时间偏移保留。打包排除本机残留的文件替换 helper，移除写入依赖和专属构建步骤。
