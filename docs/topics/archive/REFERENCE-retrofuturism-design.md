# DESIGN.md — 复古未来主义（Retrofuturism）

适用：网页、品牌视觉、三维场景、界面皮肤  
语境：千禧年前沿（约 1997–2004）及其所属的更大复古未来谱系  
版本：2026-09-30

---

## 1. 这份文件是什么

这不是潮流拼贴清单，而是一套**可执行的设计约束**。

复古未来主义的核心判断只有一句：

> 选定一个「预言年份」，只用那个年份会有的材料、字体和形状，去装一个它够不到的功能。

未来主义说「我们马上要去那儿」。  
复古未来主义说「他们当年以为会去那儿」。

设计时先锁年代，再锁情绪，再开色板。年代一混，画面会脏。

---

## 2. 定义

**复古未来主义（Retrofuturism）**  
当代创作中，对早期未来想象的回看与再演。词约在 1980 年代被叫出（常归到 Lloyd Dunn），现象更早：维多利亚科幻插画、1930s pulp 封面、1950–60s 太空时代广告，都是原材料。

两个经常叠在一起的方向：

1. **从过去看未来**  
   直接复刻当年的未来图：飞车、射线枪、圆顶城市、半透明电脑。
2. **把未来塞进过去**  
   用当代或更超前的功能，去改装某个历史年代的外形（蒸汽机里长出屏幕，即蒸汽朋克）。

情绪两极都可以成立：

- 乌托邦：太空时代、《杰森一家》、早期 Aqua
- 反乌托邦：赛博朋克、《银翼杀手》、柴油朋克的战争机器

同一套方法，乐观和幻灭都能装。差别在调色、磨损和叙事，不在「有没有金属」。

按「那个年代相信什么动力」选一条主轴。主轴之外的元素最多当点缀，不要并列当主角。

| 分支 | 预言年代 | 技术信仰 | 视觉气味 | 典型参照 |
| --- | --- | --- | --- | --- |
| 蒸汽朋克 Steampunk | 维多利亚 / 19 世纪末 | 蒸汽、齿轮 | 黄铜、皮革、飞艇 | 《天空之城》 |
| 柴油朋克 Dieselpunk | 一战–1950 | 柴油、内燃机 | 装饰艺术、军工、Noir | 二战架空、流线型飞行器 |
| 原子朋克 Atompunk | 1945–1965 | 核能、喷气 | 圆角家电、Googie、蘑菇云广告 | 《辐射》系列 |
| 射线枪哥特 Raygun Gothic | 1930–60 pulps | 「科学」本身 | 流线型、天线、飞碟餐厅 | 《杰森一家》、早期《星舰迷航》 |
| 赛博朋克 Cyberpunk | 1980s 对 2010+ | 网络、义体 | 霓虹、酸雨、扫描线 | 《神经漫游者》《攻壳》 |
| **Y2K 未来主义** | **1997–2004** | **个人电脑、互联网、消费电子** | **镀铬、半透明塑料、气泡界面** | **iMac G3、早期网页、千禧 MV** |
| Frutiger Aero | 2005–2012 | 玻璃 UI、清洁科技 | 天蓝、露珠、Vista 玻璃 | Windows Aero、早期 iPhone |

相邻风格不要混成一锅：

| | Y2K 未来派 | McBling | 蒸汽波 | Frutiger Aero |
| --- | --- | --- | --- | --- |
| 时间感 | 1998–2002 | 2000–2008 | 偏 80–90 失真广告 | 2004–2012 软件界面 |
| 气质 | 科幻乐观、塑料玩具 | 炫富甜美 | 忧郁、过期 | 天蓝玻璃水珠 |
| 表面 | 铬、半透明塑料 | 水钻、丝绒 | VHS 噪点 | Vista 玻璃、露珠 |

**本文件默认主轴：Y2K 未来主义**（千禧年消费电子那一支）。需要太空时代或赛博时，另开一节覆盖，不要把 Bondi 蓝和酸雨霓虹叠在同一屏。

## 4. 设计原则

1. **先锁年代。** 1998–2001：铬、半透明塑料、气泡按钮。2005–2009：玻璃、天空、露珠。混用必须有一层「时间旅行」的叙事理由。
2. **过时的工艺 + 超前的功能。** 张力来自这里。去掉任何一侧，就变成普通复古或普通科幻。
3. **材料暴露时代。** 铜铁、镀铬、胶木、半透明彩塑——让人一眼读出「这是哪一年的工厂」。
4. **形状服从当年工具。** 1998 年 3D 软件刚能轻松做曲线，所以圆角、blob、胶囊胜出；不要用 2015 年的直角极简去「改良」它。
5. **原件只借材质和密度，不借信息架构。** 当年导航、闪图、自动播放经不起现在的可用性。
6. **真诚优于反讽。** 原味预言是认真的。可以俏皮，不要一上来就做成梗图。
7. **一套未来，一个光源。** 高光方向统一。塑料走边缘折射，金属走镜面，不要两种高光同时抢。

## 5. 视觉代币

### 5.1 色彩

Y2K 主轴默认高饱和、屏幕优先。底可以黑或白，中间必须跳。

**主色（选 1–2 个压场）**

| 名称 | 建议值 | 用途 |
| --- | --- | --- |
| Bondi Blue | `#2A7F8C` / `#3B8C8C` | iMac 壳体、主品牌 |
| Blueberry | `#2E5AA8` | 面积色、导航 |
| Grape | `#6B3FA0` | 点缀、标题光 |
| Lime | `#8FBF3F` | 警告/活跃，少用 |
| Strawberry | `#D24A6E` | CTA 旁的糖果色 |
| Tangerine | `#E07A2F` | 短促强调 |
| Chrome Silver | `#C8D0D8` → `#8A939C` | 金属字、边 |
| Ice | `#B8D4E8` | 高光、玻璃 |

**辅色**

- 荧光粉 `#FF4FA3`、电光蓝 `#3DF0FF`、莱姆 `#C8FF4A`：只做 5–10% 面积。
- 亮白 `#F4F7FA`、近黑 `#0B0E12`：给正文和背景。

**不要**

- 莫兰迪低饱和当主色。
- 同时铺满粉、绿、橙、紫而不设主色。
- 用 2021 年 iMac 的马卡龙去冒充 1999 水果五色（前者更粉、更不透明）。

### 5.2 材质

按优先级：

1. **半透明塑料 / 果冻 PVC**（Mac、键帽、按钮）  
   厚度可见、边缘折射、内部栅格隐约透出。
2. **镀铬 / 液态金属**（标题、Logo、Discman 系物件）  
   冷灰蓝反射，高光尖，不要黄金。
3. **镭射 / 珠光**  
   短距离渐变位移，面积小于铬。
4. **像素 / 扫描线 / 印刷网点**  
   当纹理，不当主体排版。

网页实现优先 CSS 渐变 + SVG，少用照片贴图（一缩就糊，也不像当年矢量 UI）。

### 5.3 形状

- 大圆角、胶囊、水滴、blob。
- 几乎没有锋利直角。
- 硬件语言：蛋形一体、提手、侧盖、圆饼鼠标。
- 界面语言：鼓起的按钮、叠层半透明面板、圆点指示灯。

圆角半径宁可过大。Y2K 没见过它喜欢的直角。

### 5.4 字体

分三层，不要让标题字体去跑正文。

| 层 | 方向 | 例子（可替换） | 用途 |
| --- | --- | --- | --- |
| 显示 | 气泡 / 镀铬 / 赛博几何 | Orbitron, Audiowide, 自做 chrome 字 | H1、数字、Logo |
| 正文 | 当代人文无衬线 | Space Grotesk, Inter, 思源黑体 | 段落、导航 |
| 数据 | 等宽 / 像素 | Space Mono, VT323 | 读数、时间戳、假系统信息 |

规则：

- 正文必须可读。气泡字只出现在 3 个词以内的标题。
- 中文标题可用圆体或略加粗的黑体，不要用装饰艺术字硬套汉字。
- 字母间距：显示层可加宽；正文保持正常。

### 5.5 动效

原味站点动效很土。现在做，只保留「材质在动」，去掉闪图逻辑。

允许：

- 缓慢的高光扫过镀铬字（4–8s 循环）
- 按钮按下的凝胶形变
- 极慢的 blob 呼吸
- 屏幕内容的 CRT 微闪（透明度 2–4%）

禁止：

- 自动播放 MIDI / 背景音（除非用户打开）
- 闪烁 GIF 当导航
- 弹窗计数器、访客灯箱
- 为复古而复古的滚动劫持

## 6. 网页结构

信息架构用 2020 年代，皮肤用 1999–2001。

```
Hero        大标题（镀铬或气泡）+ 一句预言 + 一台硬件剪影
Proof       3 张卡片，半透明面板，hover 出金属边
Story       短文，当代排版，旁侧一条时间刻度（1998 / 2000 / 2001）
Objects     3D 或平面物件：iMac / Discman / MD，不堆
Close       单一 CTA，凝胶按钮，不要五个闪图入口
```

密度：中高，但阅读区必须留白。把「热闹」集中在 hero 和物件区。

响应式：

- 桌面：允许 3D 慢转、多层玻璃。
- 移动：关掉 transmission 重材质，改用平面半透明色块；标题改普通粗体 + 细铬描边。

无障碍：

- 正文对比至少 4.5:1。镀铬字只放在深底或加实心底。
- 动画遵循 `prefers-reduced-motion`。
- 不要靠颜色单独区分状态。

## 7. 硬件参照（千禧年 Mac）

这是 Y2K 消费电子最干净的一套实物语法。

### 7.1 机型时间

| 年份 | 对象 | 外形要点 |
| --- | --- | --- |
| 1998 | iMac G3 Bondi | 蛋形 CRT 一体，青绿半透明 + 乳白底座，顶提手 |
| 1999 | 水果五色 iMac | Blueberry / Grape / Lime / Strawberry / Tangerine |
| 1999 | iBook 蛤壳 | 圆饭盒、提手、蓝/橙半透明 |
| 1999 | Power Mac G3 Blue & White | 蓝白塔，侧门整块翻下 |
| 2000 | iMac Indigo / Ruby / Sage | 颜色加深；入门价下探 |
| 2000.07 | Power Mac G4 Cube | 8 寸正方体 + 透明罩，糖果开始收束 |
| 2001 | Flower Power / Dalmatian / Snow | 花纹失败，白色出现 |
| 2001 | Aqua 正式 | 软件追上硬件：能舔的按钮 |

2001 钛 PowerBook、2002 灯笼 iMac、铝 Unibody **不是**这条线。

### 7.2 借什么、不借什么

借：半透明叠乳白、内部栅格隐约可见、大圆角、提手、Bondi/水果色、早期 Aqua 红绿灯和凝胶键。

不借：原样苹果标做商业主视觉、2021 七色 iMac、镀铬赛博外壳（那是 Discman 系）。

Mac 是**糖果店里的家电**，不是液态金属武器。

### 7.3 3D 资产

Apple 不提供官方开源 CAD。网格版权归作者，外形与苹果标仍受商标约束。

可用起点（需逐条核对 License）：

- Sketchfab · BlackHorn860 *iMac G3 – Upgraded*（CC BY，约 14.5k 三角，屏幕分层）
- Sketchfab · Martin Lonnemann iMac G3（CC BY，低面）
- Deutsches Museum iBook SE 扫描（先读馆方许可）
- 3D Warehouse 上的 G4 Cube（格式老，需转 glTF）

落地页建议：

- 只用 glb，1–2 万三角。
- 半透明用 transmission + thickness，不要贴玻璃照片。
- 屏幕内容自己换 emissive 贴图。
- 商用或客户项目：自建简化外形、去掉 Logo，或购买明确 royalty-free 模型。

## 8. 软件界面参照（Aqua）

2000 年 1 月公布、2001 年随 Mac OS X 到来。

可借：

- 红 / 黄 / 绿窗口灯
- 水纹进度、鼓起的默认按钮
- 半透明菜单、细条纹标题栏
- 大尺寸拟物图标（到 128px 的那种「能舔」）

不要借：

- 2007 Vista Aero 的露珠风景（那是 Frutiger Aero）
- 2014 以后的扁平面
- OS 9 Platinum 灰条当「千禧年未来」（那是 90 年代残留）

硬件用 G3 半透明，UI 用早期 Aqua，两条对齐。

## 9. 与听歌设备的关系（同一套年代）

若场景需要「人当时怎么听歌」，物件层级如下，勿把 2001 年末的 iPod 提前放进 2000 年初的桌面。

1. CD 随身听 / Discman（主流便携）
2. 磁带 Walkman（便宜、仍在）
3. MD（亚洲发烧）
4. 早期闪存 MP3（Rio、Nomad，容量小、贵）
5. 电脑 + Winamp（真正改习惯的地方）

iPod：2001 年 10 月。出现即宣布「塑料糖果桌面」开始让位给白与金属。

## 10. 做 / 不做

**做**

- 一种预言年份贯穿全站
- 半透明塑料或铬，二选一当主角
- 标题装饰、正文克制
- 物件少而可认：一台 iMac 胜过五台杂牌赛博机
- 给未来一点过期感：略厚的高光、略假的 3D

**不做**

- Y2K + 蒸汽波 + Aero 三层滤镜叠在同一 hero
- 满屏不可读的镀铬段落
- 把低腰牛仔裤 McBling 和 iMac 工业设计当成同一语言
- 用自动播放和闪图证明「我懂复古」
- 把苹果商标当免费素材

## 12. 落地检查清单

发布前问这七句：

1. 预言年份写在了什么地方？别人能否一眼读出？
2. 主材质是塑料还是铬？有没有两者互抢？
3. 正文离开装饰字体后还成立吗？
4. 关掉所有动效，版面是否仍清楚？
5. 移动端是否把重材质降级了？
6. 3D / 照片里的品牌标是否处理过？
7. 这页是「过期的明天」，还是「过期的现在」？（后者是蒸汽波，走错文件了。）

## 13. 一句话工作定义

千禧年这一支复古未来主义 = **用当时刚够用的电脑，把未来做成亮闪闪的玩具。**  
银或透，鼓，撞色，再留一点「千年虫」式的兴奋和不安。

选定年份。露出材料。让功能略微超出那一年的工厂。其余删掉。
