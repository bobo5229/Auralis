# 聆听纪念成就

正式展示以真实记录逐枚选择点亮或未点亮资产；取消全局外观开关。全部徽章按原分类和里程碑顺序共存，未点亮徽章仍可检视自身材质。小尺寸继续使用静态 PNG。

## 判定口径

- 小时累计实际播放时间；重复听的时间可累计，暂停、缓冲、跳转经过的部分不计入。
- 同一自然日累计满 3600 秒计一个聆听日，每日最多一天，不要求连续。跨午夜按本地自然日拆分。
- 一张本地专辑当前收录的每首曲目，已听片段并集覆盖时长均达到自身时长的 90%，才算完整。可跨次、跨天、乱序积累，重复片段不补足未听内容。
- 现场专辑要求当前全部曲目的显示流派字段均包含 Live，大小写不敏感。标题和专辑名不参与识别，不提供手工标记。现场徽章也要求上述完整聆听条件。
- 专辑分组沿用专辑名与专辑艺术家（空缺时回退艺术家）。未知时长曲目不视为完成；没有专辑名的曲目不参加专辑判定。
- 新增曲目、修改流派或分组后按最新曲库重算。删除聆听历史后同步清除依据，不再满足条件则恢复未点亮。

## 旧历史

迁移 32 仅把已有 daily_play_stats 的按日折算时长快照一次，作为小时和聆听日基数。后续有效播放统计仍服务原档案，但不再次加入徽章时长。旧播放次数不能证明片段覆盖，故不补算专辑完成度。启用当天的旧基数与新实际时间合并，当天最多一天。

## 生命周期

播放控制器把已有播放、暂停、缓冲、跳转、切曲、结束和释放事件交给独立的 listeningProgressTracker。按秒采样、每五条提交一次，暂停和结束提交尾批。持久化以会话和序号去重；清除历史推进 epoch，使旧会话的延迟写入失效。新记录和旧档案不互相改写。

组合层只通过显式 Preload API 获取汇总；主进程校验来源、结构、数值与批次上限，在事务中保存时间和片段。成就查询派生状态，不保存永久点亮标志或虚构达成日期。检视期间固定同一份汇总，结束后应用最新状态，保留原有图片整组解码、GLSL 检视及取消流程。

当前不弹出自动检视或播放中提示。未达成文案展示当前进度，已达成显示状态。首次回算不重播批量点亮动画。
