## 保留与未采纳候选

- `capture-mac-baseline.mjs`：子代理建议作为旧工具删除。主进程复核发现其目标演示 HTML 和相关 DOM 入口仍存在，当前证据不足以认定失效，保留。
- 主进程四个构建入口、封面及元数据 worker、日志 transport、共享 IPC 和兼容类型仍有消费者，保留。
- `metadataNormalizer` 等模块有只在内部使用的导出，但实现仍参与当前业务。这属于模块可见性整理，本轮不为去掉 `export` 扩展后端修改面。
- `buildCdAlbumIndex` 等测试包装调用现用基础实现；测试专用入口不能一概判定为旧业务。基准辅助实现、兼容夹具均保留。
- Pixi peer dependencies、Iconify 图标集、类型声明、字体、演示资源及原生依赖均保留。
- UI 子代理检查了 Renderer Vue/TS/CSS、路由动态入口、模板引用和 UnoCSS 配置；现用页面与组件都有入口。语义排版角色和 Vue 运行时生成的过渡类保留。与后端相同，仅取消内部符号 `export` 的整理未纳入本轮。
