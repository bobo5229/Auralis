# 冷启动专辑闪卡验证

底图设计比较原型见 [background-prototype/README.md](background-prototype/README.md)，启动命令为 `node scripts/startup-album/background-prototype/run.mjs`。它复用正式卡片的底图、取色、排版与闪膜。

碎裂效果已接入正式“跳过”，独立碎裂原型已移除。

七种底图沿用既有疏密构图，统一搭配单层细框与封面细边，边角保留各风格的细刻线，标题和艺人区柔化细节并保留当地大块色彩。构图、合成和随机位置在正式 `rendering/backgrounds/` 中实现；同一真实封面的七款静止／倾斜对照入口及参数见 [底图比较说明](background-prototype/README.md)。

正式播放器在欢迎页完全退场后，展示一张本地可播放专辑。每次先抽取推荐方向：60% 少听、25% 久未听、15% 完全随机，再在对应候选中抽一张。设置 → 外观中的“启动时推荐一张专辑”默认开启，下次启动生效。刷新、窗口恢复及后续窗口不重复展示。

推荐仅用于启动闪卡，队列中的随机专辑播放沿用原有行为。候选按实际显示的「专辑艺术家（为空时回退歌曲艺术家）＋专辑名」分组，只统计可用歌曲并排除空专辑名。少听权重为 `(1 + 0.5 × 未听曲目比例) / sqrt(1 + 平均有效播放次数)`，避免长专辑因歌曲数量受到额外惩罚，同时照顾只听过主打歌的专辑。久未听方向仅选择有有效播放时间的专辑，以专辑内最近一次有效播放为准，权重为 `0.1 + 0.9 × min(间隔天数 / 90, 1)`；未来时间按 0 天处理，没有有记录的候选时退回等概率抽取。

最近实际展示的 10 张不同专辑持久化到 `auralis-startup-album-history`，最新在前；旧版本单条记录自动作为初始历史。冷却中专辑先排除，候选不足时从最早展示的专辑逐个放回，只有一张时允许重复。少听和久未听方向另乘艺术家权重 `1 / (1 + 0.5 × 最近三张展示中该艺术家的出现次数)`；完全随机方向在冷却后的候选中保持等概率。展示时记录，跳过和关闭不追加负面反馈；准备失败、被取消或没有展示不写历史。统计只代表 Auralis 已记录的收听行为，全部无记录时抽取自然接近普通随机。数据查询与权重计算由主进程管理的短生命周期只读 worker 完成，复用现有统计；选择与完整曲目读取共用同一只读事务，无数据库迁移或额外依赖。

展示记录只写入 `albumArtist` 和 `album`，历史及兼容的旧单条键均不保存曲目或本地文件路径。WebGL 以第一张卡面真实绘制为准；静态 PNG 等待图片加载及画面绘制，导出或解码失败时等待 HTML 卡面绘制。首帧前关闭、隐藏、卸载或开始退场均不记入冷却，上下文恢复不重复记录。

`node scripts/startup-album/run.mjs recommendation-history skip play empty disabled` 验证正式 Renderer、Preload、IPC 与数据库接入：小曲库逐步放宽冷却、展示历史落盘、跳过不改变推荐反馈、完整专辑播放、空库和关闭开关。比例边界、分布、少听和久未听权重另由定向单元测试验证；原生内存库测试验证聚合与完整有序曲目返回。

数据、封面和渲染模块与启动并行准备。欢迎页不等待推荐；退场后最多等待 1 秒，超时或用户已开始操作则取消本次展示。缺失封面使用本地占位图；WebGL 不可用时使用静态卡。播放立即从第一首顺序播放整张专辑，同时闪卡用 1.2 秒翻转落入 Playbar；跳过播放 1.4 秒的裂开、散落和淡出，不改变播放状态。裂纹约在前 0.4 秒逐渐显现，再分离、翻转和下落，最后淡出。七块碎片共用同一正面纹理、印刷遮罩与闪膜，并保留纸芯侧壁；分块随展示随机变化。减弱动效或静态卡使用 180 ms 淡出。

专辑信息仅显示在卡面中；卡片下方只保留“播放专辑”和“跳过”，不重复显示介绍、专辑名或艺术家，也不提供查看曲目与完整专辑入口。两个按钮在入场结束帧实际绘制后出现，减弱动效等待短入场结束；静态降级等待卡面加载及绘制。入场时焦点留在展示层，按钮出现后不自动转移焦点；用户按 Tab 后可依次访问窗口控制按钮、播放与跳过，并显示键盘焦点。跳过开始后隐藏操作按钮并锁定交互，焦点留在展示层；退出完成后释放渲染资源、恢复背景交互与焦点。退出期间窗口隐藏、WebGL 上下文丢失或动效偏好改变时直接完成关闭；卸载取消退出定时器与渲染循环。Esc 在入场及普通展示时仍立即关闭。

遮罩在卡片首帧绘制时从透明开始，以 200ms `ease-in-out` 淡入，最终保持原有 94% 主题底色浓度；静态降级在卡面准备好时淡入。只改变遮罩，卡片不跟随淡入，按钮独立等待入场结束。运行 `node scripts/startup-album/run.mjs backdrop` 可检查真实 Renderer 的透明度采样、200ms CSS transition、与首张卡面 WebGL 绘制的时序，并保存 `backdrop-fade.json`。

`skip` 检查按钮出现后的跳过，`skip-settled` 检查正常 1.4 秒退出、阶段画面与快捷键隔离；`skip-hidden`、`skip-context-loss`、`skip-reduced` 检查中断与降级。各跳过场景检查退出期间焦点与背景锁定、结束后的释放，以及退出后不再绘制。`controls` 检查按钮出现后不自动获取焦点、原生 Tab／Shift+Tab 焦点顺序、两个按钮的可见描边和 Esc 关闭；`controls-timing` 观察真实 WebGL 入场扫光结束帧与 DOM 按钮插入的先后关系，保存 `controls-timing.json` 和入场／停稳截图。

`node scripts/startup-album/run.mjs first-frame-cancel fallback context controls` 定向检查展示记录与焦点。集成入口在欢迎页退场前观察实际卡面 WebGL draw 和历史写入，断言正常展示只写一次、静态卡加载后才记录，且偏好仅含身份字段；`first-frame-cancel` 在真实展示层挂载后、首次绘制前派发 Esc，确认没有 draw、没有历史写入且背景解锁。`context` 保留隐藏／恢复与 WebGL 丢失／恢复检查，确认展示历史不重复写入。真实组件单测另控制首帧、原生窗口／DOM 隐藏、PNG 加载／失败、卸载与播放／跳过取消时序；这些单测不代表视觉验收。

播放落入复用同一个卡片、材质和 Canvas，捕获当前世界姿态后扩展至整个窗口，维持原来的屏幕投影。前 150 ms 上提 12 px，随后 800 ms 沿弧线翻转一圈并缩小，最后 250 ms 倾至 78°，从 Playbar 上缘没入。背景遮罩在 450 ms 内退去；卡片缩至约 80 px 高后，以 scissor 裁掉上缘以下的部分，裁切边界同步 Playbar 的 3 px 附加回弹。动画期间保留焦点和背景锁定，结束后一次性释放；窗口隐藏、尺寸变化、目标失效、上下文丢失或动效偏好切换时提前结束，不取消播放。缺少有效落点时也使用 180 ms 淡出。

原生截图采集本身可能跨越多个动画帧；需要单独查看没入的瞬间时，可运行 `play-inserting`，仅在目标 1000 ms 采集该阶段；需要检查同一张正面翻转至半圈时的镜像画面，可运行 `play-half-turn`，仅在目标 550 ms 采集该阶段。

`play` 检查按钮出现后的点击，`play-settled`、`play-small`、`play-hidpi`、`play-light` 保存上提、半圈镜像、接触和没入阶段截图及实际 WebGL 变换／scissor 数据（`play-*-drop.json`）；检查音频请求在退场前发出、完整有序队列、重复点击不重新播放、退出后停止绘制。`play-hidden`、`play-resize`、`play-context-loss`、`play-motion-change`、`play-target-lost` 检查中断；`play-no-target`、`play-reduced`、`play-fallback` 检查淡出降级。`cardDrop.test.ts` 用真实 Three.js 数学验证半圈姿态的投影连续、落点裁切和回弹清理。`AURALIS_STARTUP_ALBUM_COVER`、`AURALIS_STARTUP_ALBUM_TITLE`、`AURALIS_STARTUP_ALBUM_ARTIST` 也可用于播放场景，素材只读复制进隔离缓存。

完整卡面与碎片使用同一套支持透明度的材质程序，初始不透明度仍为 1；避免首次跳过时另编译闪膜的透明材质变体，吃掉裂纹显现阶段。碎片按需创建，退出后释放独有几何、材质和裂纹线；纹理与印刷遮罩仍由原卡片统一释放。

## 隔离集成验证

先构建，然后运行：

```powershell
npm.cmd run build
node scripts/startup-album/run.mjs
```

也可指定单项，例如 `node scripts/startup-album/run.mjs context settings`。测试使用生产 BrowserWindow、Preload、IPC 处理器、数据库结构和正式 Renderer；入口仅负责生成隔离专辑、封面与低音量测试 WAV，并通过 Electron 原生输入操作界面。WebGL 失败场景只阻断测试窗口中的 Three.js 上下文创建。

每轮创建独立 profile，同一轮多次启动复用该 profile，检查跨冷启动避重。产物保留在 `.electron-home/startup-album/`，包括 `verification.json`、默认窗口、小窗口、精简操作区、静态降级、上下文恢复及设置画面。音频检查使用 Electron 的可听状态，并核对完整队列顺序；不代表人工主观听感验收。

自动化不读取真实曲库，也不改动真实音乐文件。`hidden-timeout` 场景在欢迎页退场期间隐藏窗口，超过 1 秒后恢复，确认过期闪卡不会出现或被记录，主界面保持可操作。启动超时、迟到结果、交互取消和偏好存储失败另由定向单元测试覆盖；曲库可用性、避重及曲目排序使用 Electron ABI 下的内存 SQLite 测试。

## 闪卡渲染模块

卡片入场停稳后，仅在鼠标悬停实际卡面时跟随倾斜；鼠标移到空白区域或离开展示区，卡片平滑回到平面内逆时针 1.5° 的固定展示姿态。入场过程中不叠加 hover 倾斜，减弱动效和静态降级关闭鼠标倾斜。

首次进入以可见卡片命中为准；悬停期间同时保留固定姿态的圆角轮廓，避免四角因倾斜缩离鼠标而断触。倾斜幅度使用固定展示坐标，移出两个轮廓后复位。`hover-default` / `hover-small` / `hover-hidpi` 使用原生鼠标输入检查四角停留、圆角空白排除、停止绘制及移出复位，并记录实际提交给 WebGL 的卡面矩阵和截图。

卡面印刷图像保持原有颜色与对比度，不参与环境白光、透明涂层反射及 ACES 色调映射。虹彩与扫光在显示色彩空间内限制混合强度，并保护深色文字；卡片边缘仍使用场景光照表现厚度。`contrast-dark` / `contrast-light` 使用校准封面，通过原生鼠标输入检查九个悬停位置、移开后的状态，并在测试窗口内将真实着色器的扫光临时设为满强度，检查黑白色块的实际截图亮度。测试不增加正式接口，产物包括截图及 `*-contrast.json`。

每次展示随机选取折光空间、液态金属、光轨隧道、极光云幕、层叠纸雕、地形浮雕、丝带流场之一，并保存一个 32 位图案种子。七种风格分别在有限范围内改变花纹位置、镜像方向、曲率或间距，保留层数、材质与主要构图规律；具体参数见底图原型说明。悬停、尺寸变化、卡片旋转与 WebGL 恢复不重新随机。同一专辑刷新文字或配色时保留种子；更换专辑时重新选择，不持久化样式，也不保证相邻展示不重复。

底图按封面 48 × 48 采样的原始主色、辅助色与点缀色配色；OKLab 明度/色度映射保留构图层次。最新三种底图的饱和红色采用深绯红色阶与较弱的静止虹彩，暗底联动暖白文字；橙色、蓝绿与黑白封面保持各自的配色。无封面、透明图或取色失败使用中性底图。取色只在创建或更换专辑时执行，几何与材质不引入独立时间动画、贴图下载或额外绘制层。

封面沿用原有闪膜保护；红/绿双通道数据遮罩分别标记封面和真实文字笔画，避免深色底图被误判为印刷文字，同时保护深浅两种文字。遮罩和文字共用实际字符串、截断、字号与基线。底图通过角度控制独立虹彩；所有层仍限制每通道最大提亮为剩余亮度的 16%，新三种红色底图静止时收至 4%。入场扫光保留，静止后归零。`cardMaterial.ts` 负责分区合成，`cardCoating.ts` 和 `vendor/pokeboxFoil.ts` 保留封面处理与复用 GLSL。退出时释放卡面、遮罩、材质和几何资源。

WebGL 不可用时使用本次展示预先选定的相同底图、种子和取色绘制静态卡；上下文丢失时从当前印刷画布生成静态图，恢复后返回原来的样式。画布导出失败时仍显示 HTML 封面与文字。

底图接入的定向检查可运行 `node scripts/startup-album/run.mjs surface-red text-long contrast-light`。`surface-red` 使用合成红色封面，通过真实着色器 uniform 确认数据遮罩已接入，检查卡片四角悬停及复位，并测量静止底图的红色通道；截图和测量见 `surface-red-*.png` / `surface-red-surface.json`。七种构图与冷暖、黑白、透明取色的全面比较由底图原型的 `--verify` 覆盖，复用正式卡片实现。

卡片只保留一份正面印刷图、遮罩和闪膜材质，并以 `DoubleSide` 在旋转时继续显示同一张图；卡片背向观察时，画面会自然镜像，不绘制曲目列表或另一套内容。纸芯几何只绘侧壁，避免背向时实体底板遮住正面。跳过碎片也共用这份正面图与材质，碎裂后不会生成另一套反向图案。

卡面沿用 720 × 1032 的设计坐标，以 1440 × 2064 纹理绘制文字，画布像素比随屏幕缩放更新，上限为 2。专辑名位于封面上方，艺人名位于封面下方，均相对封面水平居中；按包含衬线和花体延伸的可见笔画范围计算中心，双行标题每行独立居中。HTML 降级显示同步居中。标题使用本地 Bodoni Moda，在字体声明中固定光学尺寸 `opsz=18`，避免按 Canvas 的 54／48 单位字号自动选择过细笔画；艺人名使用本地 Allura 连笔花体，以 0.8 设计单位同色描边轻微加强细线，文字遮罩同步描边，截断预留描边宽度。中文回退到既有源流明体；HTML 降级花体使用相同比例的同色描边。标题与艺人名各自从所在区域取色。标题为 54 个设计单位，较长时使用 48 单位并最多两行，行距 56；艺人名为 60 单位，超长截断。两者在封面宽度内各留 16 单位的内侧留白。绘制印刷图与文字遮罩前等待字体加载。封面保持完整比例，位于 `(44, 210)` 的 632 × 632 区域；标题可见笔画块的垂直中心为 136，艺人可见笔画中心为 910；使用实际字形上下界计算基线，双行标题整体居中。材质分区同步使用 `cardLayout.ts` 中的坐标。单层圆角金属细框、四角同心短弧与底部居中短线由 `cardFrame.ts` 绘入印刷纹理；主框内缩 20 个设计单位，四角短弧与主框间距为 8，底部短线宽 112，标题上方留白。金属色使用同一封面色相的低饱和银色与柔和明度渐变，角饰和底部短线比主框更淡。主框与封面细边在同一路径叠加轻微暗色底印，以保留浅底上的轮廓；封面细边位于图像区域外侧 2 个设计单位，不遮挡或裁切封面。静态降级与碎片继承同一张纹理。卡片外形与入场轨迹保持原有实现。这些字号随卡片整体缩放，属于卡面印刷排版。卡面底部只保留装饰细线，不显示 AURALIS 或曲目数量，静态降级也不显示曲目数量。保留 mipmap 并将各向异性过滤提高到 8，兼顾翻转时的稳定性和倾斜时的清晰度。

文字检查可运行 `node scripts/startup-album/run.mjs text-default text-hidpi text-small text-long`，覆盖默认窗口、2 倍屏幕缩放、900 × 620 小窗口和长专辑名。通过同一专辑的静止及原生 hover 画面检查排版，同时断言绘制缓冲区匹配屏幕像素比；截图和实际尺寸记录为 `text-*.png` / `text-*-resolution.json`。这些场景在隔离偏好中固定排除另一张专辑，以便前后对比。

`src/renderer/features/startupAlbum/rendering/` 包含正式播放器的卡片几何、材质和入场实现，接收真实专辑模型，并连接现有窗口可见性与减弱动效偏好。交互验证统一通过上述正式 Renderer 集成入口完成。

闪膜复用 [Pokebox](https://github.com/selop/pokebox/tree/7f6b1b4b6bb4684f80b49d1318b2a1c90a357b80) 的 Overlay 混合、六色色谱、柔边遮罩定向闪膜和 Voronoi 切面函数，并适配交叉光带。来源固定为该提交，完整 MIT 版权声明见 `vendor/pokeboxFoil.ts` 与根目录 `THIRD_PARTY_NOTICES.md`，构建产物保留该声明。Pokebox 的闪膜视觉源自 [Pokémon Cards CSS](https://poke-holo.simey.me/)；本项目没有引入该项目的 GPL 源码、宝可梦素材或外部闪膜贴图。卡片几何、交互、等高线、亮度保护与上升翻转入场为本地实现。Three.js 与类型依赖在项目根目录锁定为 0.180.0。

布局验证可运行 `node scripts/startup-album/run.mjs text-default text-long text-small text-hidpi fallback skip-settled`。需要检查本地真实封面时，可为 `text-artwork` 场景设置 `AURALIS_STARTUP_ALBUM_COVER`（图片绝对路径）、`AURALIS_STARTUP_ALBUM_TITLE` 和 `AURALIS_STARTUP_ALBUM_ARTIST`；脚本只读取图片并写入隔离缓存，所有曲目仍为生成的测试 WAV，不访问真实曲库数据库。截图为 `text-artwork-rest.png` / `text-artwork-hover.png`。
