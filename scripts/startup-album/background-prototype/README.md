# 闪卡底图原型

```powershell
node scripts/startup-album/background-prototype/run.mjs
```

独立 Electron 窗口比较折光空间、液态金属、光轨隧道、极光云幕、层叠纸雕、地形浮雕、丝带流场七种静态程序底图。默认并排展示新增三种，可切换全部七种或单独放大、悬停倾斜、关闭闪膜、切换展示背景或导入本地封面。全部比较按窗口宽度分为四列或两列并支持纵向滚动。默认封面由代码绘制，名称与艺术家为示例文字；导入仅替换图片，不解析音乐元数据。

“重新生成图案”会为七张卡分别生成新种子；切换视图、悬停、调整窗口和导入封面都保留当前种子。正式播放器每次展示生成一次种子，卡面旋转和静态降级共用。`backgrounds/variation.ts` 从种子确定性地产生下列参数，绘制时不调用全局随机函数，也不按帧推进随机状态。

| 风格     | 随机变化                                           | 保持的构图规律                             |
| -------- | -------------------------------------------------- | ------------------------------------------ |
| 折光空间 | 四个切面的位置、剪切、整体倾斜、横向镜像与光晕位置 | 四片大面积半透明几何面、细亮边与柔光       |
| 液态金属 | 横纵镜像、曲面纵向偏移、弯曲、宽度与间距           | 三道主曲面、一道边角反光及细刻线           |
| 光轨隧道 | 四角附近的消失点、旋转、纵向伸展、层间距与圆角     | 十层向内收束的嵌套光轨与细内缘             |
| 极光云幕 | 横纵镜像、带状曲线偏移、弯曲、宽度与云光位置       | 连续的柔和光带与雾状渐变                   |
| 层叠纸雕 | 横纵镜像、起点、间距、振幅、频率、相位与坡度       | 七层纸面共享波形规律，层间保持顺序         |
| 地形浮雕 | 四角中心、旋转、椭圆比例、半径、间距与轮廓起伏     | 七层嵌套轮廓共享起伏方向，保持高程递进     |
| 丝带流场 | 横纵镜像、三束起点、间距、线距及共享方向场参数     | 三束各二十五条连续曲线，保留疏密和流向关系 |

所有风格先绘制完整不透明基底，再变换花纹；变化限定在设计范围内，主层级与细刻线数量固定，不增加持续动画。种子只由卡片持有，不写入偏好或曲库。同一种子可在不同封面配色下复现相同构图。

七种底图按正式卡面骨架安排疏密：折光增加平行切面刻线，金属增加曲面细脊和边角反光，隧道将消失点约束在四角并收窄粗暗线，极光增加飘带细丝，纸雕增加窄切边与边缘叠层，地形增加中间高程及角部小轮廓，流场将三束曲线分布到上缘、封面背后与下缘。图案先绘制，再由正式封面与画框覆盖，因此在画框边界自然截断。

`backgrounds/composition.ts` 将花纹的低频色彩与清晰细节分开合成：标题区 `(44, 70, 632, 118)`、艺人区 `(44, 866, 632, 76)` 保留本地大块色彩，细节向模糊后的同一图案柔化，30 个设计单位渐变过渡；左右边缘恢复清晰度。没有叠加暗色椭圆或平色文字面板。合成只在印刷纹理创建／更新时运行，临时画布不加入场景或持续绘制；卡面、静态降级与碎片共用正式纹理。

同封面对照可指定本地图片和文字（图片只读复制到隔离产物，不读取真实曲库数据库）：

```powershell
$env:AURALIS_STARTUP_ALBUM_COVER = 'C:/path/to/cover.webp'
$env:AURALIS_STARTUP_ALBUM_TITLE = 'Feel My Rhythm'
$env:AURALIS_STARTUP_ALBUM_ARTIST = 'Red Velvet'
node scripts/startup-album/background-prototype/run.mjs --compare
```

`--compare` 固定初始种子 `0x12345678`，使用相同封面、字体、卡片比例和静止姿态，逐款通过原生鼠标输入捕获倾斜效果。产物在 `.electron-home/background-composition/`：`compare.html` 可切换静止／倾斜并点击放大，`comparison-rest.png` 为完整静止总览，`comparison-print.png` 为无闪膜总览，`comparison-details.png` / `comparison-hover.png` 为紧凑对照。去掉 `--compare` 可打开实时悬停窗口并重新生成图案。

该模式另在真实浏览器 Canvas 中检查七款的可见边缘随种子变化、不透明基底，以及文字区对高频花纹的柔化；同种子回放允许 Chromium 合成读回的少量 8 位舍入差，限制最大差与平均差。结果见 `comparison-verification.json`。完整 `--verify` 以实际投影的绿色字形遮罩定位深／浅文字，检查闪膜开关间的文字保护，避免把白色背景或旧坐标当作文字。

新增构图集中于 `studies.ts`：纸雕使用大幅裁切曲面与窄层间阴影；地形采用偏心、不规则的嵌套高程轮廓；流场通过固定方向场生成三组疏密变化的曲线。三种构图均保持静态，不引入独立动画。曲线生成适配 George Francis 的 `generative-utils/src/spline.js`（MIT，提交 `c26bbcfaecefd4f8302326c71fd18bfd8f413866`），完整声明保存在 `vendor/spline.ts`；去掉未使用的回调和对象输入，仅保留点元组到 SVG 路径的转换，再交由 Canvas Path2D 绘制。Haikei 仅作为层叠构图参考，未复制其源码或素材；地形是本地径向轮廓构造，没有引入 D3 或使用完整 marching-squares 算法。

底图配色随封面更新：复用播放器现有 `extractArtworkPalette` / image-q 算法，对 48 × 48 封面采样，使用原始取色结果生成主色、相近辅助色与少量点缀色。在 OKLab 中保留七种构图各自的明暗和色度范围，避免将整张底图直接染成单色或被封面亮度抬白。取色只在初始显示和更换封面时执行，静止、hover 和切换构图不重复计算。界面色块显示实际提取的原始颜色。

黑白封面使用中性明暗层次；无有效不透明像素或取色失败使用中性兜底。虹彩仍是独立材质，可关闭闪膜检查底图自身配色。损坏图片保留上一张已显示的封面与配色；连续导入只应用最后一次请求。验证覆盖暖色、蓝色、绿色、纯黑、纯白和透明合成封面，并测量实际底图像素，结果见 `palette-measurements.json`。

前四种底图在 OKLab 中平滑提升表面明度，最高增加 0.18，并在高光区域逐渐收回提升量；阴影、金属暗部和隧道凹槽显式使用 shadow 角色，保留原明度。七种底图均已移除文字区域的椭圆暗部。

新增三种采用独立的纸面色阶：通常将模板明度映射到 `0.58 + L × 0.36`，保留封面色相并控制色度。纸雕与地形阴影收窄到接缝附近，降低不透明度和模糊半径；流场提亮大面积底色。标题、艺人名分别按实际笔画的包围区域采样，比较深浅文字各自较弱的五分之一背景对比度后选色，减少区域外高光造成的误判。

饱和红色封面使用深绯红色阶：按主色色相与色度平滑确定权重，明度转向 `0.30 + L × 0.32`、色度上限转向 `0.13 + L × 0.05`，辅助面与流场线条保持在同一红色色系。文字区为暗底时使用暖白文字。判定集中于红色，橙色、冷色与中性封面保持通常色阶；封面图像与取色算法保持原有实现。

七种底图和最新取色现已接入正式开屏专辑卡片，源码集中于 `src/renderer/features/startupAlbum/rendering/backgrounds/`。本目录的相应模块仅转出正式实现；比较界面复用正式 `createAlbumCard` 的圆角几何、排版、遮罩和 Pokebox 衍生闪膜材质，避免两套效果分叉。背景保持静态，只有闪膜随悬停角度变化；原型没有正式入场、播放或跳过行为，这些流程使用上级目录的集成验证。

默认使用正式卡片的分区虹彩：独立数据遮罩的红通道标记封面、绿通道记录文字笔画，底图不再按亮度被识别为文字。封面沿用原有处理，文字排除闪膜，底图使用更明显的定向彩色反射；每通道最大提亮仍为剩余亮度的 16%。遮罩与文字共用绘制函数、相同的两倍精度，并在退出时释放。可用“虹彩：分区增强 / 原有方式”在同一底图与角度下比较，原有方式仅作为原型内的历史对照保留。

新增三种的红色基底在静止时降低光谱混合、彩色反射和分面覆盖，提亮预算随红色权重从 16% 收至 4%；倾斜时逐渐恢复彩色掠光及最高 16% 的预算。此参数只作用于背景遮罩，封面和文字继续采用各自的保护逻辑。导入新封面时同步更新每张卡的材质 uniform，不重建材质。

验证补充同角度截图、封面像素一致性、文字保护、深色底图的可见变化与亮度上限检查，结果见 `foil-measurements.json`。每次运行使用独立 profile，避免已打开的比较窗口占用验证缓存。

```powershell
node node_modules/typescript/bin/tsc -p scripts/startup-album/background-prototype/tsconfig.json
node scripts/startup-album/background-prototype/run.mjs --verify
```

验证使用隔离 Electron profile，通过原生输入切换方向、悬停、切换闪膜与主题，并检查小窗口及合成封面导入；导入用程序构造的 File 触发真实 change 路径，不自动操作系统文件选择器。截图、构建与报告保存在 `.electron-home/card-background-prototype/`。验证不等于正式播放器验收。

第一轮明度调整使用同姿态的合成红色封面对比，历史截图保存在 `before-brighter-surfaces/`，历史采样见 `brightness-measurements.json`。红色方向调整前的浅色版本保存在 `before-deep-red/`。

当前 `new-studies-red-foil.png` / `new-studies-red-plain.png` 分别记录深红基底的闪膜开关，`new-studies-red-hover.png` 记录倾斜反光。验证对三种底图的底部区域逐一测量 RGB，要求静止闪膜开启时红通道均大于绿、蓝通道的两倍，结果见 `red-surface-measurements.json`。截图使用合成红色封面，不能替代用户原始专辑封面的最终视觉判断。

接入前的静止截图补充测量保存在 `deep-red-comparison.json`：当时封面内部采样与调整前一致，暖白文字像素在闪膜开关间的平均最大通道差小于 0.17，底部采样遵守 4% 提亮上限。文字行间背景采样与辅助文字颜色的对比度第五百分位为 4.62～6.44；这只覆盖历史记录的采样区域。

运行器仅在回环地址提供编译产物；窗口关闭后停止服务。Renderer 不具有 Node、文件系统、Preload 或 IPC 能力，导入使用浏览器 File API。正式播放器按用户选择在每次展示时随机使用七种底图之一。
