# LRC 编辑面板布局 Demo

直接使用浏览器打开同目录的 `lrc-editor.html`，无需安装依赖或启动服务。仅展示歌词编辑面板，引用项目现有 typography 和共享面板 CSS；请保留它在仓库中的位置。

采用原创模拟歌词、无声模拟进度和内存保存，不连接 Electron、真实曲库、文件系统或网络。保存到标签和同目录 LRC 均只模拟反馈，不实际写入文件。刷新页面会丢失草稿和模拟保存结果。

布局：共享面板标题 → 单行时间工具 → 模拟播放进度 → LRC 文本容器 → 保存目标与保存按钮。无播放器主界面、歌词预览、TTML 编辑或格式转换控件。

可操作：原文编辑、按光标所在行替换/插入当前时间、单行 ±0.1 秒、撤销/重做、两种模拟保存和未保存关闭提示。空白/信息行不打点；含多个时间戳的行需手动编辑。打点后留在当前行。

快捷键：Ctrl / Command + Shift + Enter 打点，Ctrl / Command + S 模拟保存；文本区 Ctrl / Command + Z 撤销、Ctrl / Command + Shift + Z 或 Ctrl + Y 重做。空格和方向键保留文本编辑行为。
