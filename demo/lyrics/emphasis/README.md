# 歌词强调交互 Demo

在仓库根目录运行：

```powershell
node demo/lyrics/emphasis/serve.mjs
```

打开 <http://127.0.0.1:4196/demo/lyrics/emphasis/>。使用仓库已有的 Vue、Vite 和字体，无需安装依赖。退出服务使用 Ctrl+C。

## 体验路径

1. 点击“编辑强调”，在增强 LRC 中点选计时片段，再次点击取消。已有四处示例标记，包括单字“慢”和多字片段“心海”。一个计时片段始终是一个选择单位。
2. 点击行左侧时间选择要试听的行，或直接选择该行中的片段。点击“试听本行”，从行开始前 0.8 秒播放，到下一行前停止。
3. 暂停可观察浮起、缩放与光晕的当前姿态；拖动进度可比较任意时刻。关闭“强调效果”可以对照。
4. 切换“普通 LRC”，点击整行进行标记。普通行与没有明确结束边界的增强片段使用 1.5 秒动效，遇到下一片段、下一行或音频结束提前收尾。
5. 点击“完成编辑”返回聆听模式，文字上的选择提示隐藏；点击歌词恢复为跳转整行。右上角展开按钮切换聆听预览。
6. 可选择本地音频和 UTF-8 LRC，试听自己的歌曲。读取仅发生在浏览器本地，标记写入当前站点 localStorage，不修改音频或歌词文件。

支持撤销、清除此行、深浅主题、音量、手动滚动后恢复跟随和系统减弱动效。Escape 退出编辑及聆听预览；空白区域的空格切换播放；编辑模式的 Ctrl/Command+Z 撤销选择。

## 原型边界

这是独立的 Vue 交互原型，复用生产 `parseLrc`、活动行查找和语义字号；不接入正式窗口、曲库、数据库或文件写回。播放使用独立示例媒体元素，仅为 Demo 提供真实音频时钟。正式集成应接入现有 `usePlayback`。

标记按完整歌词原文关联，刷新后保留。同一原文再次载入可恢复；歌词文字或时间变化后视为新文档。正式的标记迁移策略待设计。Demo 允许从任意歌词行编辑，手动进入编辑时暂停自动跟随，试听时恢复跟随；这些交互供用户体验确认。

`demo.wav` 是本仓库脚本生成的 32 秒原创合成伴奏，无人声。它用于观察动效节奏，不代表真实演唱同步的听感验收。重新生成：

```powershell
node demo/lyrics/emphasis/generate-audio.mjs
```

动画使用实际媒体时间计算姿态；暂停、向前/向后跳转、重播都重新求值。默认最大缩放 1.13，抬升 0.14em，平滑进入和回落。固定时长、幅度、曲线属于本次试验值。系统开启减弱动效时保留文字高亮和编辑提示，关闭浮起、缩放与光晕。

## 设计与验证

延续现有 Auralis 操作表面：炭灰 / 冷瓷灰、暖白文字、现有 Plus Jakarta Sans / HarmonyOS Sans SC 和语义字号；歌词沿用专用大字号，操作区保持轻量。选择下划线和淡底色表达持久标记，文字颜色表达播放状态。没有修改全局设计规范或正式样式。

运行中的真实页面已在 Electron 38 / Windows 的隔离 profile 中检查。`check.mjs` 操作实际 Vue 控件、真实媒体元素和页面布局；仅验证输出通过零增益静音，分析器确认解码信号非零。验证范围包括选择、撤销、保存恢复、整片段处理、整行处理、暂停、跳转、试听边界、减弱动效、本地歌词导入、异常提示和桌面/窄窗口。

结果和画面保存在 `output/lyric-emphasis-demo/`。当前 38 项交互及几何检查通过，深浅主题、1280/800/390 CSS 像素宽度已截图查看。补充的真实 CDP 触摸输入检查验证了手动滚动暂停跟随、切行保持位置及恢复入口。

独立只读复核发现的手机试听区遮挡、触摸滚动跟随两项问题已修复；审查者复查源码、断言和更新截图，两项均判定 resolved，给出 ship 结论。此次独立复验没有重复运行检查器。用户的真实演唱试听与动效强度选择待体验反馈。

复现验证时先启动服务，再从仓库根目录运行（使用独立 profile）：

```powershell
node --input-type=module -e 'import {spawn} from "node:child_process";const env={...process.env};delete env.ELECTRON_RUN_AS_NODE;const p=spawn("node_modules/electron/dist/electron.exe",["demo/lyrics/emphasis/check.mjs"],{env,windowsHide:true,stdio:"inherit"});p.on("exit",code=>process.exit(code??1))'
```

检查器仅清理自己的隔离 profile 内站点存储，不接触正式应用数据。视觉检测器的静态扫描提示 Plus Jakarta Sans 属常见字体；这里沿用项目已有字体体系。其余视觉结论来自实际截图与几何检查。
