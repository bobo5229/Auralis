# 最近添加方形歌单封面：时间沉积

入口：[HTML demo](recent-added-time-sediment.html)。直接使用 Chrome / Edge 打开 HTML，离线可用，绘制需要 WebGL2。代码、着色器及纹理生成均内嵌，无需启动服务、安装依赖或访问真实曲库。

## 设计与交互

- 默认并排展示浅色和深色模式；可单独展示一个主题。每个预览左侧是 `aspect-ratio: 1` 的方形歌单封面，右侧是标题、统计和时间刻度，页面背景保持主题底色。
- 时间范围对应独立配色：7 天灰玫瑰与暖杏，30 天雾紫与灰蓝，90 天青灰与烟蓝，全部琥珀与褐紫。深浅模式保留同一组色相，调整明度。
- 7／30／90 天及全部共享范围状态，分别使用 2.6／3.8／4.9／6 的回溯深度参数 `reach`，不对应独立图层数量。范围越长，近处主曲面越向左侧让开，更多远处颜色显露；两条曲面向右上方逐渐收窄、淡入背景。
- 图案采用不对称的 S 形时间褶皱：主曲面从左下进入，中部转折后向右上延伸，另一条更浅的曲面从反方向弯入。主曲面近宽远窄，两条曲面的深度共同决定唯一的连续取色位置；深色集中在左下，周围保留浅色空间，右上有微弱柔光。曲面轮廓通过宽幅渐隐融入背景，不使用描边、边缘阴影或逐层颜色覆盖；固定噪声参与取色形成磨砂质感，标题和统计在封面外。
- 停留时以 6 秒为一轮沿 S 形走势流动。主曲面的横向位置由主波与二倍频次波共同驱动，并轻微舒展、收拢；反向曲面的响应晚约 1 秒。波形由下向上传播，位移幅度向远处减小，柔光同周期轻微明暗变化；噪声采样位置不随时间移动或重新随机，没有整图旋转或缩放。7 天的远处颜色更早淡入背景，范围越大，可见的远处变化越多。
- 范围切换使用 1000 ms 的形态及线性 RGB 配色插值。扩大范围时近层向外让开，并短暂不对称地掀起，露出更早的层；缩小范围时反向合拢。范围过渡期间冻结慢速循环的相位，完成后从该相位继续；重复切换从当前形态、掀起量和颜色继续，重复选择当前范围不重播。
- 「暂停动效／继续动效」控制循环与范围过渡。暂停、系统要求减少动态效果、文档隐藏或所有可用画布离屏时，停止动画帧，将未完成的范围切换收敛到最新选择，保留循环相位。恢复时从暂停相位继续，不累计隐藏期间的时间；静态模式下切换范围立即应用。系统减少动态效果时禁用手动恢复按钮，并保留用户原本的暂停选择。
- 两组切换器支持方向键、Home／End 和可见键盘焦点。
- 曲目及统计全部为模拟数据；页面不播放音频、不修改资料库。列表用于观察封面信息区与下方内容的衔接；窄窗口中封面和信息纵向排列，封面保持方形。

## 自有绘制实现

`SedimentRenderer` 使用原生 WebGL2 在一个全屏三角形上绘制封面，未引入运行库。主要步骤：

1. 用自下而上的 `along` 坐标定义两条反向弯曲的中心线。主曲面的基线从左下斜向右上，叠加一次完整正弦转折形成 S 形；反向曲面的曲率、入口和出口不同，避免对称或同心。两条曲面的横向宽度向远处缩小，按到中心线的归一化距离计算高斯密度，宽幅渐隐到背景。移除旧的偏心弧面及对数深度计算。
2. 两条曲面分别提供局部时间深度，以各自密度加权得到唯一的 `timeDepth`，再统一取色；反向曲面密度较低、深度偏向浅色。动画相位沿 `along` 推迟，主曲面的位置与宽度一起变化，反向曲面延迟响应。主波与二倍频次波保持 6 秒周期闭合；`spread`、`shift` 和瞬态 `peel` 参数在扩大范围时把近处主曲面向左侧让开，反向曲面向另一侧展开，同时 `reach` 增大显露过去。快速切换保留当前掀起量并平滑收敛。
3. 用三次 B 样条把七个颜色组织为一条连续调色曲线。每个位置只读取附近四个颜色，以非负、总和为 1 的权重混合；色标之间二阶连续，没有每个色标处强制停住的纯色平台，也不会因插值产生颜色越界。两端重复端点颜色，平滑收敛到首尾色。取色在线性 RGB 中进行，最后编码回显示颜色。
4. 用固定种子的 xorshift32 生成 256 × 256 单通道纹理，两主题共享。固定的低频、中频和较细尺度噪声在取色前扰动 `timeDepth`；CSS 像素坐标中的细颗粒也参与深度扰动，使颗粒取得邻近颜色。采样位置不随时间或范围改变，颜色会随着深度场运动自然变化。
5. 以 `timeDepth` 与 `reach` 的关系计算宽幅背景过渡，用 `fwidth` 扩展抗锯齿范围，并结合两条曲面的联合密度，让画面周围自然留出浅色空间。远处颜色少量向背景褪色，柔光位于右上方 `(0.86, 0.15)`。最终颜色上仅保留强度很小的固定抖动，主要磨砂质感来自取色前的扰动。
6. `phase` 参数只驱动深度场位移与柔光，不进入纹理采样坐标。两主题由单个动画调度器共享相位，绘制频率限制为约 30 fps；范围过渡也使用同一调度器，避免循环叠加。上述连续性与权重性质来自实现公式，实际观感仍需运行验收。

像素比例最高 2 倍，单画布不超过约 100 万像素。循环仅在有可见、可用画布且动效开启时调度，不在每帧读取布局尺寸；离屏的画布跳过绘制，全部离屏时停止循环。初始化、尺寸或显示状态变化时可补画；恢复时重置计时基准，不追赶暂停期间的时间。页面进入浏览器往返缓存时暂停，返回时恢复；销毁时取消动画帧并清理观察器、事件监听及 GPU 资源。上下文丢失时显示 CSS 占位色，全部上下文丢失时停止循环，恢复后重新创建 GPU 资源并按当前选择与相位继续绘制。上述为实现策略，实际帧率与资源开销未测量。

本轮借鉴 [Paper Grain Gradient](https://shaders.paper.design/grain-gradient) 及其 [0.0.81 版本源码](https://cdn.jsdelivr.net/npm/@paper-design/shaders@0.0.81/dist/shaders/grain-gradient.js) 的组织方式：连续形态场 → 取色前噪声扰动 → 调色曲线 → 背景融合。S 形褶皱时间场、B 样条配色、纹理生成及绘制生命周期由本 demo 独立实现，未复制上游 shader 或重新引入其包、CDN、噪声资源和 API 调用。文档中的链接仅供参考，HTML 不请求外部资源。

不支持 WebGL2 或着色器初始化失败时，受影响的主题显示明确提示和随范围变色的 CSS 占位渐变；占位渐变不代表完整的沉积与磨砂效果。
