# 最近添加 · 入库手记

独立设计 demo。直接用浏览器打开 `index.html`，无需安装或启动服务。

以日期和入库记录组织内容：多张专辑组成一条记录，补入已有专辑的曲目单独呈现，单张专辑使用横向版式。支持记录类型筛选、右侧日期跳转、唱片预览、深浅主题切换。

全部日期、批次与收藏状态均为示例；复用仓库本地封面与字体。不读取真实曲库，不调用后端，不播放音频，不替换正式页面。预览弹窗只列出示例曲目节选。

`verify.cjs` 使用项目 Electron 隐藏窗口检查素材加载、筛选、预览和窄屏溢出，截图与隔离 profile 写入 `.electron-home/recent-added-journal/`。
