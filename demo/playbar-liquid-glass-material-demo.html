1. 哪些改动降低了纯黑实心感？
  • 基底不透明度重塑：将单一硬编码 rgba(16, 20, 26, 0.36) 改为双层低密度暖黑介质 rgba(18, 17, 16, 0.22) + rgba(32, 27, 22, 0.18)，底色不再因单一过深色值形成密实黑色胶囊遮盖。
  • 表面光学微光泽 (Top Sheen)：在基底上叠合 linear-gradient(180deg, 0.07 -> 0.015 -> trans)，给整条玻璃赋予连续物理表面，即便背底全黑，也能感知到玻璃面上的环境微光漫反射。
2. 哪些改动提高了中右侧 Liquid Glass 感知性？
  • 双重微边缘立体度 (Rim Highlights)：重新激活 ::before 并采用 inset 0 1px 0 rgba(255,255,255,0.24) 顶反光 + inset 0 -1px 0 rgba(0,0,0,0.42) 底压暗，勾勒出完整胶囊的厚度轮廓。
  • 专辑 Tint 超轻量级长距衰减：向中部展开柔和衰减梯度（26% -> 14% -> 5% -> 1.5% -> 0%），打破中右侧与左侧的光学孤立断层，同时严控整体不偏色。
  • 轻量级连续磨砂：注入适度 backdrop-filter: blur(26px)，使背底穿透内容与边缘折射实现丝滑融合。
3. 最值得后续迁移回正式代码的参数
  • --auralis-liquid-glass-bg-base: 极薄暖黑基础层。
  • --auralis-liquid-glass-rim-highlight: 顶部 1px 精致内高光与底部压暗。
  • --auralis-liquid-glass-layer-sheen: 连续表面漫射光。
  • player-bar-album-tint 在 liquid-glass 下的长距渐变算法。
