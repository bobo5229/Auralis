# 专辑长按落盘动效 Demo

启动交互预览：

```powershell
node demo/albums/album-drop/preview.cjs
```

也可直接用浏览器打开 `index.html`。页面没有外部资源依赖。

- 长按任一封面 500ms：封面放大，其他区域模糊，CD 抽出并平抛落入 Playbar。
- 飞行中段绕水平轴完整翻转一圈，经过银色盘面、薄侧边和封面印刷面；落盘前减缓翻转并倾斜。
- 落盘时建立整张专辑的演示队列，从第一首开始顺序播放。
- 三首曲目都是本地生成的合成试听音，每首 18 秒；演示封面、专辑和艺术家名称为样例。
- 支持自动选边、指定左右方向、慢放、重置、暂停、切歌、进度跳转和队列查看。
- 提前松手、移动超过 9px 或滚动会取消长按；Esc、失焦和窗口尺寸变化会取消正在进行的动效。
- 键盘聚焦封面后可按 `Shift+Enter` 预览；“减少动效”默认跟随系统偏好。

这是独立交互原型，没有接入正式播放器、真实曲库、偏好或数据库。
