# 软盘收纳交互原型

直接用浏览器打开 `index.html`。独立静态 demo，不连接曲库、不写入数据。

- 点击盘签选择，再次点击或使用「取出软盘」抽出；点击展示中的软盘或「放回盒中」归位。
- 分类标签定位对应专辑，左右方向键或箭头按钮在当前分类内翻找。
- 合盖收好全部软盘，再打开继续；Esc 放回当前软盘。
- 支持减少动态效果偏好。分类与六张专辑是演示内容。

视觉：烟灰透明盒盖、灰绿色硬壳、金属滑片和纸质专辑标签。使用 CSS 几何绘制，展示收纳动作，不代表历史软盘盒精确复刻。

封面复用 `../listening-journal/assets/`，来源及权利记录见该目录 `sources.json`。保留目录相对位置；仅本地原型展示，封面权利属于原权利人。
