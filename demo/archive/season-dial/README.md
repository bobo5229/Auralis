# 季节拨盘原型

直接用浏览器打开同目录的 `index.html`，无需启动服务或安装依赖。

原型沿用 Auralis 的界面字体、四季配色、侧栏和播放栏比例，独立于正式页面、路由及后端。
歌曲、歌手、次数和封面均为示例；播放按钮只预览选中与暂停状态，不播放音频。

- 左侧四季拨盘，右侧为可滚动的示例歌曲列表。
- 点击季节字或彩色圆弧，选中季节沿最短路径转到上方；拨盘约 940ms，文字与列表约 510ms。
- 支持拨盘下方的左右按钮，以及季节按钮上的方向键、Home 和 End。
- 中央年份取本地年份，默认选中当前季节；冬季范围使用同年 1、2、12 月。
- 右上角切换明暗主题；系统减少动效时直接切换，页面隐藏时结束文字与榜单的换场。
- 卡面使用本地 CSS/SVG 渐变，空闲时无帧循环、轮播或自动播放。
- 布局针对桌面 900×620、1180×760 及宽窗口设计，窄浏览器提供上下排列。

字体直接引用仓库现有资源，许可保留在原资源目录中。不读取或写入真实曲库及偏好。
