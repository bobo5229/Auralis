# 通高双列软盘 HUD 静态原型

浏览器直接打开 `index.html`，无需启动 Auralis 或本地服务器。

面板填满页头下方的可用高度，五张软盘每行两张、共三行；第三张固定展示选中框。外框采用低亮度蓝灰切角线条，选中框采用青蓝细线与局部辉光。保留正式声迹页软盘的金属滑片和封面标签语言。字体与封面引用仓库现有资源，封面来源见 `../listening-journal/assets/sources.json`。

日期、选中专辑与插盘入口均为静态示意，没有点击、拖拽、插盘、播放或持续动效。演示日期固定为 2026-10-05，素材不来自真实聆听记录。标题和底部信息固定在面板内；高度不足时只在软盘陈列区纵向滚动，保持两列。

仅用于确认 HUD 视觉，尚未接入正式声迹页或验证左右分区布局。桌面和窄窗口截图由独立 Electron 离屏窗口生成，运行 `node_modules/electron/dist/electron.exe demo/archive/floppy-hud/capture.cjs`；结果写入本目录，独立配置与缓存写入系统临时目录。
