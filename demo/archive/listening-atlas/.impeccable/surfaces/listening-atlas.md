# 声迹 · 聆听长廊

范围：index.html、atlas.css、atlas.js。模式：Operate。用户选择个人聆听档案，并要求先交付可交互原型。

## Direction contract

THESIS：让用户沿着时间回到音乐。日期是一条连续可操作的路径，封面承载当天的记忆；统计从属于作品。

OWN-WORLD：冷白与浅灰绿底色、森林绿文字与选择态、无衬线大日期、完整正方形封面。分区依靠留白与细线，作品列表不套卡片。复用本地 OPPO Sans 与现有拉丁 UI 字体，不使用复古设备、像素、霓虹与票据。

STORY：先看到某一天及其代表作品，在当天专辑间选择，再沿日期滑轨访问邻近日子；时间索引展开整年，选择日期后回到该日。

FIRST VIEWPORT：上方页名和时间索引入口；正文左为日期与当天累计，中间为约 420px 的原色封面，右为作品信息、曲目入口及五张以内的专辑目录；下方横向日期滑轨，月份导航与记录状态可见。

FORM：七个候选依次为时间图册、摄影接触印样、地层切片、收藏架、连续聆听路径、展览墙、周记。种子 468dbad3 指定第五项，采用连续聆听路径。目录挑战者提供的密度、固定刻度、明确指向、稳定标签、作品优先与尺度纪律融入导航清晰度，不借用其外观。用户已授权先做原型；本轮直接以代码呈现可交互方案，不记录全项目构建偏好。

FINISH：同会话检查桌面、窄桌面与窄屏实际画面及关键事件，最多一轮集中修正；交付设计规格与素材来源。用户禁止未授权代理，因此不创建独立审查代理，明确检查为同会话自测。
