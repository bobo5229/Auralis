# 声迹 · 聆听长廊

直接用浏览器打开 [index.html](index.html)，无需安装或构建。请保留该目录在仓库中的位置，以便加载已有字体与封面。

本轮是“个人聆听档案”的可交互候选方案，尚未接入正式声迹页。

## 体验

- 点击右侧专辑目录，切换主封面和当天聆听数据；支持上下方向键。
- 用日期箭头、下方日期滑轨和「时间索引」回看不同日子。
- 日期滑轨支持鼠标拖动、滚轮、触屏滚动、左右方向键及 Home / End。
- 月份或年份浏览保留正文选择，选定某一天后才更新正文。
- 「查看当天曲目」在正文展开，Esc 或关闭按钮收起并返回焦点。
- 「时间索引」在桌面显示全年，窄屏显示可切换月份的数字日历；支持方向键与 Esc。
- 页脚「预览状态」可检查空记录、读取失败和加载状态。

演示时钟固定为 2026-10-05，历史从 2025-01-01 开始。2026-10-04 与 2026-10-02 为明确的空记录示例，未来日期不可选择。

## 设计与素材

原型围绕日期、完整封面、当天专辑目录和连续时间路径组织。视觉采用冷白、灰绿、森林绿及本地无衬线字体。规格见 [DESIGN.md](DESIGN.md)。

所有聆听次数、时长与示例曲目为合成数据，不读写曲库数据库或音乐文件，不调用 IPC 或播放能力。专辑封面复用已有 [listening-journal 资产](../listening-journal/assets/sources.json)，来源及权利归属保持不变，未作为自由授权素材。字体复用仓库已有 OPPO Sans 与 Plus Jakarta Sans，原许可保留在对应字体目录。

## 验证

通过本地 Electron / Chromium 实际加载静态原型，检查桌面、窄桌面和窄屏画面；实际视口与结果记录在 [.impeccable/review/results.json](.impeccable/review/results.json)。

已操作专辑切换、快速连续选择、曲目展开、跨年日历键盘移动、日期选择、鼠标拖动滑轨、错误重试及状态预览；检查焦点返回、未来日期禁用、减少动态效果与横向溢出。封面加载完成，未记录页面错误。`node --check atlas.js` 与目标文件格式检查通过。设计扫描发现的空状态对比度问题已修正。

检查为同会话自测，未创建独立审查代理；未运行正式应用、全仓测试或真实播放验收。
