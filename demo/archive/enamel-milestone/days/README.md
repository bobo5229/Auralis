# 日日相伴 · 连续天数徽章

打开 `index.html` 查看「一周相伴」徽章：午夜蓝珐琅承托北斗七星，大小有别的银色星芒以细银线连接，数字 7 与 DAYS 位于星图下方。支持已点亮／未点亮、深浅背景和 96px 对照。当前是静态设计原型，条件指连续 7 天聆听，未接入真实聆听记录或颁发规则。

打开 `30.html` 查看「月下相伴」徽章：深蓝紫珐琅上，两段银边珍珠月牙弧构成 3，深靛蓝至珍珠白的月相环构成 0。月相环右上方局部嵌入虹彩，下方独立标注 DAYS。条件指连续 30 天聆听，月相为艺术意象。提供已点亮／未点亮、深浅背景和 96px 对照。

打开 `520.html` 查看「倾心相伴」徽章：深石榴红珐琅承托三道心形银色音轨，左上方的一段音轨嵌入局部虹彩。心形底部以短银线交叠收束，520 与 DAYS 在图案下方独立排布。条件指连续 520 天聆听，提供同样的状态、背景和缩小对照；预览页通过导航互通。

打开 `100.html` 查看「百日留声」徽章：深青珐琅上，银色唱针构成数字 1，两枚带同心沟槽的椭圆唱片构成两个 0。音乐物件本身组成 100，下方只保留 DAYS，不再叠加一组数字。条件指连续 100 天聆听，提供已点亮／未点亮、深浅背景与 96px 对照；五枚徽章通过页内导航互通。

- `assets/days-7@2x.png`：660 × 740 透明 PNG。
- `assets/days-7-unlit.svg` 与 `days-7-unlit@2x.png`：沿用小时系列统一未填釉金属胚，仅替换浅浮雕数字和单位。
- `assets/days-30.svg` 与 `days-30@2x.png`：330 × 370 透明 SVG 与 660 × 740 透明 PNG，月牙弧和月相环直接组成 30，DAYS 为矢量轮廓。
- `assets/days-30-unlit.svg` 与 `days-30-unlit@2x.png`：同一未填釉金属胚，常规浅浮雕 30 与 DAYS。
- `assets/days-520.svg` 与 `days-520@2x.png`：330 × 370 透明 SVG 与 660 × 740 透明 PNG，520 与 DAYS 均为矢量轮廓。
- `assets/days-520-unlit.svg` 与 `days-520-unlit@2x.png`：同一未填釉金属胚，浅浮雕 520 与 DAYS。
- `assets/days-100.svg` 与 `days-100@2x.png`：330 × 370 透明 SVG 与 660 × 740 透明 PNG，唱针与唱片直接组成 100，DAYS 为矢量轮廓。
- `assets/days-100-unlit.svg` 与 `days-100-unlit@2x.png`：同一未填釉金属胚，常规浅浮雕 100 与 DAYS。
- `manifest.json`：连续天数、名称、图案、釉色和资产路径。

金属包边复用百小时原型的几何与渐变；深蓝凹面、四芒星的金属侧壁与切面、两个局部虹彩星芯构成北斗主题。星图采用四星斗身与弯折斗柄，参考 [NASA 北斗资料](https://science.nasa.gov/image-article/apod-2006-march-17-the-big-dipper-cluster/)，位置和大小为适应徽章构图而简化，不作为观星图。96px 下以数字 7、斗形和轮廓识别为主，DAYS 应由产品外部文字补充。此资产尚未接入翻面授章动效。

520 版保留相同银框与倒角，采用酒红周边积色、玫瑰色受光区、心形凹面和银线接触阴影。三道音轨的粗细不同，另以低对比内刻线补充细节；虹彩嵌饰通过矢量遮罩限制在单段音轨内，色片布局确定，不依赖贴图、字体或 GLSL。96px 下以心形、520 和石榴红釉色识别为主，DAYS 由产品外部文字补充。两枚资产都尚未接入翻面授章动效。

100 版使用不同于小时系列中央数字唱片的整体构图：两枚椭圆环形音轨具有外缘、三道沟槽、暗色标签与轴孔；左侧数字 1 保留斜顶与竖向轮廓，同时增加转轴、弯折唱臂、唱头和接触第一枚音轨的针尖。虹彩限制在第一枚唱片的一小段音轨及底部嵌饰。三个物件同高排列，以整体数字轮廓保证缩小后的辨识；未点亮版仍采用统一数字模板。此资产尚未接入播放器或翻面授章动效。

30 版的上下月牙以两套珍珠釉渐变区分弧面，银色包边、偏移侧壁与接触阴影提供厚度。0 保留连续外轮廓和完整深色内孔，渐变月相与虹彩嵌饰均限制在环面内。96px 下保留 30 的清楚轮廓，细节在大图中查看。未点亮版沿用统一金属胚和常规数字轮廓；尚未接入播放器或翻面授章动效。

打开 `365.html` 查看「一岁相伴」：深琥珀珐琅上，香槟金太阳由浮雕圆面与长短放射刻纹组成，四段连续的银边釉色环象征四季，配四个主刻度与细刻线。365 与 DAYS 在轨道下方独立排布。采用复古天文仪器意象，条件为连续 365 天聆听。提供 `assets/days-365.svg`、`days-365@2x.png` 及同名 `-unlit` 版本，尺寸沿用 330 × 370 SVG / 660 × 740 PNG；未点亮版本只保留统一金属胚、普通数字与单位。尚未接入播放器或翻面授章动效。

从仓库根目录重新生成：

```powershell
node demo/archive/enamel-milestone/days/build-assets.cjs
Start-Process -FilePath ./node_modules/electron/dist/electron.exe -ArgumentList 'demo/archive/enamel-milestone/days/render-assets.cjs' -WindowStyle Hidden -Wait
```

生成器依赖现有 `../demo.js` 的材质层和 `../hours/assets/hours-unlit-template.svg` 金属胚。渲染脚本默认导出十种 PNG，并检查 SVG 引用、透明度、预览页的图片加载、导航路径、状态与下载切换、背景切换和窄屏容纳。设置 `BADGE_ID=days-365` 可仅导出并检查周年版本，其他徽章可按 manifest 中的 ID 指定。截图默认输出到临时目录，或通过 `BADGE_CHECK_OUTPUT` 指向已有目录。
