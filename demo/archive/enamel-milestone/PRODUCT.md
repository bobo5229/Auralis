# 珐琅里程碑徽章原型

本文件只约束 `demo/archive/enamel-milestone/`。

- 用途：验证 SVG、CSS 三维变换和少量 JavaScript 能否承载珐琅徽章的 2.5D 观感。
- 用户已指定：沿用参考徽章的金属、珐琅、幻彩与分层构造，不使用 WebGL、GLSL 或 Ray Marching。
- 演示内容：一枚“百小时聆听”徽章；里程碑与达成状态均为合成演示数据。
- 主要行为：移动光标观察高光，拖动或用方向键调整视角，展开五层结构，切换配色，重播点亮。
- 范围：可离线打开的独立网页，不接入播放器路由、IPC、数据库或真实聆听记录。
- 成功标准：第一屏即可看到徽章；桌面和窄屏操作可用；减少动态效果时仍能切换视图和配色。
