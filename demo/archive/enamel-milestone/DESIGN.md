# 珐琅徽章观察台

深墨绿色背景承托蓝色珐琅与银色金属，徽章采用圆角六边形轮廓。中心采用“唱片年轮”：三道同心音轨与轴孔表达音乐，一道完整虹彩环表达阶段完成。金属浮雕数字 100 为视觉主体，HOURS 明确单位。孔雀绿、琥珀金复用同一几何。光泽为人为设计的渐变近似。

小时系列静态资产位于 `hours/`：10 小时「初响」采用青蓝釉面、唱针与偏置唱片；100 小时「成章」复用原有正面；500 小时「共鸣」采用孔雀绿、两组交织声波和局部虹彩；1000 小时「久伴」采用靛紫唱片套与局部暖金。四枚共用六边形底座、银色倒角与放射刻纹，数字和单位均为矢量轮廓。预览页用同尺寸并排展示，并提供深浅底和 96px 对照。新增资产不改变现有授章动效。

未点亮状态统一使用未填釉金属胚：沿用六边形几何，降低包边反光，以深灰凹面和内缘暗槽保留实体感；取消专属图案、彩釉、虹彩和装饰性刻纹，仅保留同尺寸的浅浮雕小时数与 HOURS。四个数字版本由同一模板生成，另提供不含数字的空白 SVG/PNG。预览默认展示未点亮状态，支持与彩色资产切换对照。

静态材质采用多道窄倒角、暗槽与偏移亮边；釉面带低对比放射刻纹、周边积色和金属接触阴影。虹彩局限在完整环形嵌饰内，以固定种子生成的不规则半透明色片模拟箔片。数字采用暗色侧壁、接触阴影与金属正面；音轨的低对比刻线不与数字争抢注意力。高光使用柔和局部反射，避免贯穿画面的硬边斜带。表面层深度压缩至 3px，合拢时强调嵌合关系。

桌面左右排列实物展示与操作区；760px 以下改为纵向。徽章独立层叠，裁切只在各 SVG 内部进行。观察台以九片底座提供有限侧面厚度，五个表面层支持展开。授章副本替换薄片底座，按同一圆角轮廓采样 96 个 CSS 侧面，并增加银色背板、A 字母刻印和 AURALIS 铭文；侧面从背板延伸到正面金属框，支撑侧视翻转。正反面隐藏各自背面，避免镜像文字穿透。

沿用仓库 OPPO Sans 和 Plus Jakarta Sans。普通文字采用 12–18px，原型展示标题采用 42px / 1.45，窄屏 32px / 1.4，属于此独立展示页的标题例外。

悬停微倾斜、拖动和键盘调整共享同一角度状态；展开有固定观察角。授章由“重播达成时刻”触发，使用窗口中心的独立徽章副本，停稳后不再移动。0–2.5 秒通过 Web Animations API 编排背面登场、斜轴半圈翻转和正面落定：初始 Y 轴 -180°，约 1.01 秒经过 -90° 侧面，正面越过 11° 后回摆 -3°，2.2 秒回正。金属窄反射、釉面柔光、虹彩与数字高光在正面可见后接入，余光约 2.4 秒结束。2.5–3.4 秒通过不规则 SVG 遮罩与固定范围位移滤镜显现深蓝黑面板；之后文字和按钮渐入。淡入施加在外层容器，避免透明度将 preserve-3d 主体压平。结束时取消材质动画并移除墨水滤镜，没有持续循环。数字使用矢量轮廓，避免 SVG 文字在三维动画中的合成重影。

授章使用原生 dialog 管理模态焦点。待显现文案 inert，Esc 与空白处可全程退出；关闭清理计时器和 Web Animations、恢复滚动和入口焦点。系统减少动态效果时直接到完成态；播放中切换该偏好同样会立即取消动作并恢复完整材质。窄屏缩小徽章和面板，矮窗口压缩排版与非必要文案，徽章锚点始终为可视区域中心。

已检查 Electron 桌面、390px 窄屏及展开截图，补充 96px / 160px 缩小截图与三种配色。96px 下保留整体轮廓与 100 数字，细刻纹与 HOURS 不作为此尺寸的主要信息载体；完整里程碑名称由外部界面提供。静态布局与主要交互通过隔离运行检查。未进行真实触屏操作或播放器集成验收。

授章追加检查背面登场、接近 90° 的侧视帧、正面回摆、墨水扩散和完成态截图、390×844 窄屏与 844×390 矮窗口，以及中途 Esc、重复播放、收下、退出后清理和减少动态效果。验证初始背面朝向与最终正面朝向，人工复查背面文字正向和侧边厚度。使用 Electron offscreen 渲染与 CDP 键盘输入验证；不据此声称真实播放器集成或持续帧率性能已验收。
