# 侧立专辑 Demo

直接在浏览器中打开 [index.html](index.html)。页面使用本地字体和原创 SVG 示例封面，可离线运行，不连接曲库、Preload/IPC 或播放服务。

- 默认以 78° 侧立，露出窄封面和 14px 书脊；画面只包含专辑本体。
- 鼠标悬停后向前抽出、转正；离开交互区域后归位。
- 每张专辑独立处理 3D 厚度；收回时连续转回设定角度并回插，遮挡从右向左逐步交还相邻专辑，不经过额外的侧转姿态。
- 原位置、抽出路径和完整封面共同保持 hover，展开后仍可从底部排行数字切换相邻专辑。
- 支持 Tab 聚焦、左右方向键、Home / End 切换和 Esc 归位；触屏点击查看。
- 底部可调侧立角度、排列间距、抽出距离，也可重置；右上角切换明暗主题。
- 窄窗口仅展示区域横向滚动，遵循系统“减弱动态效果”设置。

本 Demo 用于确认空间角度和抽出动效，示例专辑与排行均为虚构内容。
