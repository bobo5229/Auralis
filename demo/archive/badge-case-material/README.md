# 铝盒外框与黑色海绵内胆

独立材质原型，聚焦铝框的拉丝、倒角和前侧厚度，以及黑色海绵的孔隙、贴合徽章轮廓的浅槽与接触阴影。

```powershell
node demo/archive/badge-case-material/serve.mjs
```

打开 <http://127.0.0.1:4198/>。可通过 `BADGE_CASE_PORT` 改变端口。全部字体、纹理、徽章图片均来自本地，无网络素材。

- 顶部切换小时、天数、专辑；单排排列，空间不足时支持触控板横滑、滚轮和两侧箭头。
- 点击一枚徽章将其移开，观察空槽；再点原槽放回。也可以「全部取出／全部放回」。这是材质观察操作。
- 右下角切换深浅展示环境，铝盒与黑色海绵保持自身材料颜色。
- 徽章使用既有 330×370 GLSL 导出 PNG，页面不创建 WebGL 上下文。

本版是材质 demo，尚未接入正式播放器，也未实现完整的中央放大检视动线。

已在隔离 Electron 中完成 15 项运行检查，覆盖全部分类素材加载、取出与放回、横向箭头与滚轮、键盘操作，以及 1440／900／390px 布局；深浅环境和空槽均已截图复查。报告与截图位于 `output/badge-case-material/round-2/`，只代表本材质原型。

## 材质与几何

`generate-materials.mjs` 用固定随机种子生成两张可平铺纹理。海绵是微孔高度场与固定左上受光，铝材是横向加工细纹；两者各以 2× 密度提供细节。生成记录位于 `assets/provenance.json`，不使用第三方纹理或修改徽章资产。

```powershell
node demo/archive/badge-case-material/generate-materials.mjs
```

凹槽直接读取原徽章 SVG 外轮廓，包括圆角；用槽壁、上侧内阴影、较暗的海绵槽底表现深度。徽章略小于槽口，表面稍突出。盒沿通过表面、倒角、内侧加工槽和前侧壁分层形成厚度。

## Direction contract

- 模式：Experience；延续 Auralis 徽章的几何、配色、命名与通用字体规格。
- 首屏：一只横向、精致写实的银色铝盒，连续的黑色海绵内胆，一排带短名称的静态徽章。
- 材料：冷灰哑光拉丝铝、细密微孔海绵；固定左上受光，浅切槽与贴合的接触阴影。
- 观察动作：移开徽章后，槽口、内壁和槽底应能清楚区分；分类切换与横向浏览均可实际操作。
- 范围：只新增本目录原型与相应验证输出；产品组件、真实用户数据与全局设计系统不变。
