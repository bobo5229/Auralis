# 长静音检测 demo

使用仓库自带 FFmpeg 的 `silencedetect`，离线检测合成音频的长静音。页面先演示 A → B 连续播放，再提供原音频和处理后的单段试听对照。独立于 Auralis 正式播放器，无需安装依赖或启动服务。

在仓库根目录执行准备与验证：

```powershell
node demo/playback/silence-detection/prepare.mjs
node --test demo/playback/silence-detection/sequence.test.mjs demo/playback/silence-detection/app.test.mjs
```

这个命令只生成测试素材、执行断言和写入报告，不打开页面、不播放声音。需要仓库已有的 `resources/audio/ffmpeg.exe`。

手动启动 demo：

```powershell
Start-Process .\demo\playback\silence-detection\index.html
```

页面可直接离线打开。顶部选择衔接方式，点击“开始播放 A → B”。A 是低音和弦，声音持续 4 秒，结尾有 3 秒静音；B 是 4 秒高音和弦。支持停止、重播和调节音量。

- 跳过静音 + 交叉淡化：默认模式，A 最后约 2 秒渐弱，B 最初约 2 秒同时渐强，总长约 6 秒。
- 跳过静音直接衔接：无重叠，总长约 8 秒。
- 保留静音作对照：等待 A 结尾 3 秒静音，总长约 11 秒。

两段是独立的 Web Audio 音频缓冲，在同一个音频时钟上预先排程。交叉淡化时，B 在 A 有效结束前启动；两个独立 GainNode 使用互补余弦包络，A 从 1 降至 0，B 同时从 0 升至 1。重叠不超过任一段有效时长的一半，按当前 48 kHz 样本帧取整。直接衔接时，B 的启动时间就是 A 的结束时间。

页面进度更新不负责触发切歌或音量变化；重叠期间同时高亮 A/B，并显示交叉淡化状态。音频数据随本地 `report.js` 加载，避免离线页面请求音频时的跨域限制。播放由用户点击触发，页面不会自动播放；下方单段试听与顶部连播互斥。

## 本轮规则

- 静音阈值：−60 dBFS；至少持续 1 秒。
- 检测音频内所有静音区间，只处理与开头或文件结尾相连的区间。
- 单段对照首尾各保留 0.15 秒余量，保护音乐收尾；中间停顿完整保留。
- 两段衔接使用 FFmpeg 检出的 A 尾部静音起点，不加额外静音余量；B 从头播放。淡化作用于实际声音，A 的尾部静音不参与混音。
- 整段静音单独标记，保留原音频供检查，不生成空音频。
- 试听副本来自 FFmpeg 实际解码的 PCM；音频分析时间轴归零。正式播放器的时间戳、预加载及交叉淡化接入留待后续验证。

## 自动验证

12 组真实 FFmpeg 检查覆盖：长尾静音、首尾静音、中间停顿、短静音、无长静音、轻微底噪、明显底噪、单声道仍有声音、渐弱收尾、全静音，以及 MP3、AAC 有损压缩后的长尾静音。

检查检测边界是否符合预期、应保留的 PCM 是否完整、试听副本能否被 FFmpeg 重新解码，并核对输入文件的 SHA-256 保持一致。MP3/AAC 使用有损编码的边界容差。

另生成 3 组衔接验证音频并由真实 FFmpeg 检查：原始拼接保留 3 秒中间静音，跳过后的拼接没有长静音；两段 PCM 完整相接。交叉淡化使用 FFmpeg `acrossfade` 的 `hsin` 曲线生成独立参考，逐样本核对互补余弦混音的结果、总时长和无长静音。

`sequence.test.mjs` 使用可控音频时钟运行真实排程模块，检查 A/B 启动边界、阶段变化、停止、重播、完成和旧异步回调隔离；另检查两个音量包络的起止时刻、互补性、短片段限制及对照模式音量保持。它不打开页面或连接声卡，不代表浏览器实际出声验收。

`app.test.mjs` 保留真实页面脚本与排程模块，模拟 DOM 和音频接口，检查媒体互斥、失败重试及初始化资源释放。缓冲或 GainNode 创建失败时，断开尚未发布的主音量节点并关闭本次创建的 AudioContext；成功初始化后的上下文继续复用于重播。

所有生成音频、逐例 FFmpeg 日志、`report.json` 和供离线页面读取的 `report.js` 仅写入已忽略目录 `.electron-home/silence-detection-demo/`。不读取真实曲库，不改写正式设置。

参考：[FFmpeg silencedetect 文档](https://www.ffmpeg.org/ffmpeg-filters.html#silencedetect)。本 demo 采用预先检测加试听副本的方式；尚未接入正式播放器，也未进行真实音乐的听感验收。
