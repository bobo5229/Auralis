# 带专辑取色的液态金属原型

目标是验证用户提供的黄绿液态金属参考：专辑色构成金属主体，宽大曲面缓慢形变，连续高光沿曲面滑动。当前交付是独立材质原型，正式播放器未接入。

## 启动与体验

在项目根目录运行：

```powershell
node demo/playback/liquid-metal/serve.mjs
```

打开 <http://127.0.0.1:4176/>。依赖使用项目已有的 Vite、image-q 4.0.0（MIT）和 culori 4.0.2（MIT），不使用 CDN。需要支持 WebGL 2 的浏览器；该入口需通过本地服务打开。

- 默认为「柠檬黄绿」配色样本，也提供冰蓝、玫瑰铜、黑白样本；这些不是实际专辑。
- 上传或拖入真实专辑封面，自动提取最多六个颜色及其占比。图像只在浏览器本机处理。
- 调节流速、褶皱尺度和反射柔度。褶皱尺度数值越大，单位画面内曲面细节越多。
- 「暂停流动」冻结材质，调节参数或配色仍会重绘；「重置材质」恢复初始形体与参数。
- 「纯背景」隐藏控制，Esc 或「显示控制」恢复；「歌词预览」显示模拟信息，供判断背景与文字的关系。
- 「参考图」展示用户提供的原始基准，仅用于比较，不参与背景贴图。

## 实现方式

| 阶段 | 原型实现                                                         | 作用                                             |
| ---- | ---------------------------------------------------------------- | ------------------------------------------------ |
| 取色 | 封面缩至 48×48，image-q WuQuant 六色量化，OKLab 最近色统计覆盖率 | 保留主色、辅助色与强调色的主次关系               |
| 曲面 | 两层低频 fBm 域扭曲，宽波面叠加局部旋转和少量褶皱                | 同时形成舒展的大曲面与局部收紧区域               |
| 法线 | 对动态高度场做小步长有限差分                                     | 让高光随真实的曲面朝向变化，减少像素块边缘       |
| 反射 | 用反射向量采样程序化的虚拟棚拍环境：宽灯面、窄灯带、有色暗缝     | 产生连续反射带和金属明暗层次                     |
| 配色 | 覆盖率决定调色板区间，颜色在线性 RGB 中参与表面染色及环境反射    | 专辑色成为材质主体，亮处适度降饱和，暗部保留色相 |
| 输出 | 单个全屏三角形、片元着色器、柔和高光压缩                         | 控制实现体积和每帧绘制开销                       |

这里只将粗糙度映射为反射带的柔度，是面向效果的近似着色；不是完整 PBR、真实三维流体求解或光线追踪。高度场不能表现曲面的自遮挡和真实相互倒影。

初始参数为 `speed=0.7`、`folds=1.15`、`roughness=0.12`。时间连续累积，配色和参数变化不会重置动画；重置操作显式回到 `time=9`。绘制分辨率按 DPR 与长边上限约束，额外乘以 0.85；尺寸变化后更新，不在 CSS 上给背景叠加整体压暗或模糊。

生命周期已实现页面隐藏时停帧、启动时尊重系统减少动态设置、页面卸载释放资源，以及 WebGL 上下文丢失时停帧、恢复时重建程序与缓冲区。手动「继续流动」用于用户主动比较动态效果。

## 接入正式播放器的计划

1. **先确认材质方向。** 用同一封面比较流速、曲面尺度、反射柔度；重点确认明亮度、曲面重量感和连续高光。目前局部卷褶比参考图简单，应在材质确认阶段决定是否增加局部形体控制，不能仅增加高频噪声。
2. **拆出可复用渲染模块。** 将原型 renderer 转为 Renderer 内部的 TypeScript 模块，提供 `setPalette`、`setMaterial`、`pause/resume`、`resize`、`dispose`；着色器单独维护。失败时回退到现有流动背景或语义底色。
3. **接入封面取色。** 使用现有 `artworkUrl`，通过请求版本校验阻止旧封面提交；封面变化时插值新旧调色板，保持曲面时钟连续。缓存按封面标识限定容量，bitmap 在取色后关闭。
4. **接入现有共享播放状态。** 主界面与全屏分别配置材质，但共用播放状态；验证播放/暂停、进入/退出、页面隐藏、减少动态、上下文恢复与卸载。播放速度和帧率分别决定，先以观感验证确定暂停策略。
5. **验证文字与性能。** 使用明亮、深色、单色和多色封面检查歌词、辅助文字、灰白轨道与焦点可读性；优先使用局部、受控的文字区域处理，避免再次用过低的整体亮度抹平材质。对真实应用进入、再次进入和切曲路径测量帧耗时，再决定最终分辨率和质量档位。

## 验证与证据

启动本地服务后运行：

```powershell
node demo/playback/liquid-metal/verify.mjs
```

验证器使用项目安装的 Electron，开启沙箱和隔离的临时 userData，只加载本原型。包含着色器真实编译与绘制、时间推进画面差异、暂停后停帧、三个材质控件、重置、损坏图片、真实图像取色、窄窗口布局、参考图和 WebGL 丢失/恢复。截图与数据位于 `captures/`，不读曲库或实际播放器数据。

本次最终采样：实际画布 1360×850，运行帧率约 59 FPS；改变曲面时间后有可见画面变化，暂停后连续采样没有新增绘制，WebGL 恢复后继续绘制且 `gl.getError()=0`。这是当前机器上的隔离原型结果，不是整应用性能结论。

预览文件：`captures/preview.png`、`captures/material-reference-size.png`、`captures/motion-preview.mp4`。视频由固定时间步长的真实着色器帧合成，用于查看流动形变，不用于测量帧率。

当前仍需用户判断金属质感是否符合预期；尚未接入实际播放/切曲和语义配色系统，也未完成正式播放器的文字对比度验收。
