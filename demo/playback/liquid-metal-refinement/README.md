# 液态金属镜面反射迭代

在现有 Auralis 算法上比较反射结构。左侧直接打包当前生产 shader；右侧保留其噪声、域扭曲、高度场、法线与六色权重，加入镜面棚拍环境、深暗反射、宽窄高光、线性光输出映射及可关闭的第二处局部卷曲。

## 打开

直接用 Chrome / Edge 打开本目录 `index.html`，离线可用。也可在项目根目录用独立 Electron 窗口打开：

```powershell
node demo/playback/liquid-metal-refinement/run.mjs
```

需要浏览器入口时运行：

```powershell
node demo/playback/liquid-metal-refinement/serve.mjs
```

打开 <http://127.0.0.1:4180/>。启动前如已编辑源码，先重建：

```powershell
node demo/playback/liquid-metal-refinement/build.mjs
```

使用项目现有 esbuild、image-q 与 culori，不引入依赖、CDN 或外部服务。正式播放器代码不在本次原型修改范围内。

## 比较

- 默认是银蓝与金色样本，可切换蓝棕、纯银、玫瑰铜和深灰，也可选本地封面取色。
- 两侧使用相同累计时间、曲面尺度、反射柔度、颜色和权重。按 1× CSS 像素绘制，长边上限同为 1600。
- 「局部卷曲」设为 0，迭代版与生产算法的高度场完全相同，可以单独判断反射的贡献。
- 再将「镜面强度」设为 0，迭代版回到当前算法的输出，可作逐像素基线检查。
- 「暗部深度」控制反射环境的底光与黑色反光板；「反射柔度」同时影响两侧亮带宽度。
- 「仅迭代版」适合检查大画面；「迭代 / 参考图」使用用户本次提供的原图；「纯背景」充满窗口，Esc 返回。
- 歌词预览是相同的示意文字，用于观察反光与文字的竞争关系，不代表正式播放器的文字验收。
- 暂停冻结公共时间轴，配色与参数仍可重绘；重置恢复 `time=9` 和默认参数，保持当前暂停状态。
- 页面隐藏时停止动画，系统减少动态开启时暂停；可以主动点「继续流动」比较。上下文丢失停帧、恢复时重建资源。

## 算法范围

新反射仍由高度场法线和 `reflect` 采样程序化环境：宽灯面、窄灯条、相邻黑色反光板和沿灯面的亮度变化。反射方向改变会自然压缩或伸展这些灯带。窄灯带按像素覆盖过滤，减少收紧处的闪烁；暗部保留有色的宽反射，深黑集中在反光板附近。高光与暗部在线性光中组合，经带暗部趾段和高光肩部的映射转为 sRGB。

局部卷曲同时增加第二处慢速旋涡与两项低幅次级波面，没有增加噪声层数；关闭后仍回到原始高度场。

参考图仅展示，不参与 shader 纹理或背景绘制。仍是单遍高度场近似，不包含三维自遮挡、相互倒影或流体模拟；不能保证重现参考图全部局部结构。

生产 shader 通过明确锚点插入原型扩展，构建时会检查锚点唯一性。生产算法变化后需重建并重新确认对照，不依赖旧原型 shader 副本。
