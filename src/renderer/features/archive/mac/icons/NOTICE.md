# Pixelarticons

The archive desktop uses the free Music, Album and Chart SVG icons from Pixelarticons.

- Source: https://github.com/halfmage/pixelarticons
- Revision: `8275e0af7c16aa40c54ea2b90b7af83b1fe4eb4c`
- Original files: `svg/music.svg`, `svg/album.svg`, `svg/chart.svg`
- Copyright: 2019 Gerrit Halfmann
- License: MIT; see [LICENSE](LICENSE).

The SVG geometry is unchanged. Icons render inline at their native 24×24 size,
centered in a 32×32 desktop slot, and inherit the button's foreground color.
