# 唱片室语义字号体系

## 审计结果

2026-10-04 初次审计检查 `CdAlbumsPage.vue`、`CdTrackList.vue`、`CdViewSwitch.vue`、`CdVibrationStyleSwitch.vue`、`CdFocusLyrics.vue` 和 `CdSpectrumPreview.vue`。唱片室已有独立字体与字号变量，定义集中在 [cdTypography.css](../../../src/renderer/features/albums/styles/cdTypography.css)。本次在这套体系上收敛重复规格，补齐行高及使用规则，保留原有字号和排版。

- 初次收敛时信息内容与曲名同为 14px / 1.5；导航与振动选项同为 12px / 20px。相同规格改为引用共享语义角色。随后按右侧曲名的阅读需求，将 `track` 独立设为 16px / 1.5，继续复用 EB Garamond 展示字体。
- 播放错误、加载状态和普通文字按钮此前没有显式行高，依赖继承。本次为这些角色明确保留 `normal`，让字体自身的行框继续决定高度。
- 数量与碟片分组标题原有 `normal` 行高保留。紧凑播放信息的 17px、15px 行高直接参与网格行高，继续独立管理。
- 歌词已读取局部字号变量，再按弧长、透视与文本测量缩放。SVG 单行文字使用字形几何，不增加无效的 CSS 行高约束。
- 专辑列表、专辑详情和全局 Tooltip 使用各自体系，不在本次调整范围内。

## 字体与作用域

后续振动交互改为图标的左键开关、右键切换模式，已移除 `CdVibrationStyleSwitch.vue` 及其文字选项；模式名称通过全局 Tooltip 显示，不再消费唱片室 `nav` 字号。

变量定义在 `.cd-page` 与 `.cd-view-switch`，通过唱片室样式入口加载；浏览／检索切换即使不在页面容器内，也有完整的局部角色。页面内的顶部质感切换继承 `.cd-page` 角色。浅色、深色和封面取色共用字号体系。

| 字体角色            | 字体与用途                                                                  |
| ------------------- | --------------------------------------------------------------------------- |
| `--cd-font-display` | EB Garamond；专辑标题、名称及展示文字。数字优先使用 Source Serif 4 数字子集 |
| `--cd-font-text`    | Source Serif 4；标签、导航、说明                                            |
| `--cd-font-number`  | Source Serif 4；日期、数量、编号、时间，独立数据沿用齐线等宽数字            |
| `--cd-font-lyrics`  | 引用展示字体；弧形歌词及平面回退歌词                                        |
| `--cd-font-cjk`     | 沿用现有中文衬线字体后备栈                                                  |

字号与字体家族分别管理；字号角色不强制字体、字重或颜色。默认字重由 `--cd-type-weight` 管理，配色沿用画布语义颜色。

## 共享规格

变量命名为 `--cd-type-<角色>-size` 与 `--cd-type-<角色>-line-height`。下表中的比例行高按字号计算，例如 14px / 1.5 对应 21px。

| 角色      | 字号 / 行高   | 用途                                         |
| --------- | ------------- | -------------------------------------------- |
| `body`    | 14px / 1.5    | 信息正文                                     |
| `caption` | 12px / 1.7    | 信息标签；数量与时间复用字号，保留自己的行高 |
| `control` | 12px / 20px   | 质感切换、文字导航                           |
| `note`    | 13px / 1.5    | 版权说明及次要文字                           |
| `action`  | 13px / normal | 普通文字按钮，字号引用 `note`                |

## 页面角色与几何变体

组件继续引用已有用途名称；相同规格在定义处引用共享角色，避免每个组件维护相同数值。

| 页面角色                 | 字号 / 行高                    | 消费位置                                                         |
| ------------------------ | ------------------------------ | ---------------------------------------------------------------- |
| `title`                  | 36px / 1.25                    | 专辑标题；800px 以下用 `title-compact-size` 28px，保持 1.25 行高 |
| `section`                | 20px / 1.25                    | 曲目区标题                                                       |
| `nav`                    | 引用 `control`                 | 顶部质感、文字导航                                               |
| `label`                  | 引用 `caption`                 | Album Artist、Release Date、Composer 等标签                      |
| `value`                  | 引用 `body`                    | 信息字段内容、Composer 名称                                      |
| `fine`                   | 引用 `note`                    | 版权内容                                                         |
| `count`                  | 12px / normal                  | 专辑曲目数量                                                     |
| `mode`                   | 11px / 16px                    | 曲目列表播放顺序                                                 |
| `track`                  | 16px / 1.5                     | 曲名，复用 EB Garamond 展示字体；行高 24px                       |
| `track-artist`           | 11px / 1.5                     | 曲目艺人                                                         |
| `track-number`           | 11px / 1.7                     | 曲目编号                                                         |
| `disc`                   | 11px / normal                  | 多碟专辑分组标题                                                 |
| `playing`                | 18px / 1.3                     | 展开状态的当前播放曲名                                           |
| `playback`               | 16px / 1.3                     | 浏览状态的播放文字；专辑文字用 `playback-album-line-height` 1.25 |
| `focus-song`             | 14px / 17px                    | 聚焦状态的紧凑曲名                                               |
| `focus-album`            | 13px / 15px                    | 聚焦状态的紧凑专辑名                                             |
| `time`                   | 12px / 16px                    | 播放时间                                                         |
| `lyrics` / `lyrics-flat` | 基准 24px / 20px；SVG 几何排版 | 弧形歌词 / 平面回退歌词；实际字号可随可用空间缩小                |
| `notice`                 | 13px / 22px                    | 无歌词提示                                                       |
| `status`                 | 14px / normal                  | 加载与空状态                                                     |
| `error`                  | 11px / normal                  | 播放错误                                                         |
| `debug`                  | 11px / 20px                    | 可选频谱诊断信息                                                 |

`focus-rows` 组合紧凑曲名行高、专辑行高与 5px 间隔。曲目行固定 64px、编号列宽和歌词避让属于布局几何，修改字号时需同时检查这些约束，不能把行高改动当作纯视觉调整。

## 使用规则

1. 新增文字先选择现有语义角色，字号与行高成对引用。字体家族、字重及颜色按文字用途另行选择。
2. 多个用途共享同一规格时，在 `cdTypography.css` 中建立角色引用；组件不重复写数值，也不借用全局 `--auralis-type-*` 来定义唱片室文字。
3. 当前规格相同不代表用途相同。保留 `value`、`track` 等页面角色，便于后续按用途单独调整；基础角色改变会影响其全部引用方。
4. 新的排版例外在此文档注明用途与几何约束。`normal` 是保留现有字体行框的明确选择，SVG 歌词按几何计算属于独立例外。
5. 字号调整检查长标题、较多 Composer、多碟曲目、紧凑播放信息与长歌词；涉及窗口断点时检查对应尺寸的实际渲染。

初次建立体系时保持字号层级。右侧曲名后续增至 16px / 24px，曲目行仍为 64px；字体资源、窗口布局和歌词缩放算法保持原有实现。

## 初次建立体系时的验证

类型检查、受影响 Vue 文件的 ESLint 及相关差异检查通过。使用真实唱片室页面与组件、模拟曲库及播放接口做隔离渲染，在约 1600px、1200px、780px 三档窗口宽度对照修改前后采样：专辑标题、数量、曲目标题和编号的字号、行高、字体及元素高度一致。另检查信息标签、正文、版权、区块标题、播放顺序和振动选项的计算样式，均符合角色定义，并查看浅色、深色画面。

这些结果覆盖组件排版与变量接入，未进行完整应用曲库浏览验收，也未覆盖所有长文本组合。
