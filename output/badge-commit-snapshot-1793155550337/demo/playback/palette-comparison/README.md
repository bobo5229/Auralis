# 封面取色比较

直接用 Chrome / Edge 打开 [index.html](index.html)。单文件、离线可用，图片与脚本均已内嵌；不需要启动服务或 Auralis。

## 使用

- 左侧选择同一张封面，对比现有 Wu、调整选色后的 Wu、OKLab K-means。
- 三列均展示原始选色、统一适配后的纯色画布、候选色群及占比、实际前景对比度。
- “全部封面”将整个样本组排成对照表，点击色块可放大。
- “放大观察”铺满当前浏览器视口；用左右按钮或方向键切换同一封面的算法，Esc 返回。浏览器 F11 可进一步进入全屏。
- 明度和彩度上限同时作用于三列与总览，“重置适配”恢复 L = 0.34、C 上限 = 0.075。
- 可批量添加本地封面；文件只在当前页面内解码，不上传、不写入曲库、不持久保存。刷新恢复内置样本。

内置 8 张真实封面：Melodrama、Post、Feel My Rhythm、Kind of Blue、1989、Abbey Road、Unknown Pleasures、The White Album。另有 3 张明确标注的合成边界样本，用于观察白底小色块、近似色渐变与对比色竞争、纯灰输入。真实封面保留其实际底色，包括近黑底中原有的微弱色调；不预先改色。

## 比较约定

1. 每张图解码一次，共用同一份 48 × 48 RGBA；透明度低于 128 的像素不参与。与现有采样方式一致，整图缩放，不裁边、不做主体识别。
2. **现有 Wu** 直接调用正式 `extractArtworkPalette` 并使用 `dominant`，不使用其旧背景适配结果。候选色群由原型复现相同 Wu 参数与近似色合并过程，仅用于解释占比。
3. **调整后的 Wu** 复用同一 Wu 参数（最多 5 色、每通道 3 位直方图），额外按色相合并，再作面积主导、彩度最多 10% 加分的评分。具体阈值在页面说明和 `algorithms.ts` 中公开，属于本轮待比较策略，并非既定产品规则。
4. **OKLab K-means** 最多 5 个中心；先按 OKLab 量化直方图选择最大色桶，再用加权最远点确定后续中心，不使用随机数；最多 30 次 Lloyd 迭代。与调整后的 Wu 共用后续合并和评分，便于观察聚类差异。
5. 所有结果共用 `adapt`：固定 OKLCH 明度、保留色相、限制但不抬高彩度；二分降低彩度直到进入 sRGB。主次文字和图形控件分别检查 4.5:1 / 3:1，计算实际 sRGB 合成和取整后的颜色。无彩封面不被强制染色。
6. 三列相同的输出照实显示，不添加人为偏移。固定明度会抹平部分原色明暗差异，这是本次比较背景色相与彩度的共同条件，不代表将来的产品参数已确定。

歌词、进度和播放图形均为静态示意，不播放音频。没有接入正式全屏界面、专辑标识、曲库、IPC 或偏好存储；本原型不验证正式产品的“同专辑稳定换色”集成行为。

## 重建与验证

在项目根目录运行，复用项目已安装的 esbuild、image-q、culori、TypeScript 和 Electron，不增加依赖：

```powershell
node demo/playback/palette-comparison/build.mjs
node node_modules/typescript/bin/tsc -p demo/playback/palette-comparison/tsconfig.json --noEmit
node demo/playback/palette-comparison/verify.cjs
```

重建使用当前正式取色源码；`index.html` 是构建时的独立快照。素材均保留在本地，重建不请求网络。新增内置封面时编辑 `samples.json` 并放入对应文件；本地导入无需重建。

验证在隐藏、沙箱开启且使用独立临时 userData 的 Electron 窗口中加载真实原型，不启动 Auralis 主进程业务。覆盖图片加载、11 个内置样本、有效/损坏/全透明封面导入、纯色输入、确定性、默认与参数端点的前景对比度、选择/重置/总览/放大/键盘退出及 1540、1024、540 CSS px 布局。截图与报告写入忽略的 `captures/`。这不构成正式播放器运行验收或性能基准。
