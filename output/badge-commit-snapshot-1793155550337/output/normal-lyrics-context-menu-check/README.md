# 普通右侧歌词繁简菜单验证

正式普通/全屏歌词组件、共享菜单、焦点事件、浮层定位与 DOM 布局运行于 Electron 离屏窗口。测试注入合成歌词与播放状态，使用临时 userData 和内存 partition；未读取真实曲库、音乐文件或播放真实音频。

`results.json` 记录：深浅主题单项菜单及边界、繁简切换和保存、原歌词保留、键盘打开、Esc 返回焦点、面板收起关闭菜单、进入全屏关闭菜单、两种模式共享选择、纯文本滚动位置保留、写失败提示与恢复、滚轮关闭和空歌词禁用。各项检查通过。

代表画面：`light-menu.png`、`dark-menu.png`、`plain-after-switch.png`。`review.cjs` 保留检查脚本，依赖本地 browser-preview 服务 `127.0.0.1:5188`。

自动检查：菜单、普通同步歌词、偏好和显示投影共 13 项定向测试通过；Renderer 类型检查、相关 Vue 文件 ESLint、格式与差异检查通过。未进行完整桌面重启或真实音频播放验收。
