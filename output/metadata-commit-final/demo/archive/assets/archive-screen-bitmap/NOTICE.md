# Archive Screen Bitmap

This subset contains 33 unmodified glyphs from GNU Unifont 16.0.04, embedded
in `classic-mac.html` as hexadecimal bitmap data. Chinese glyphs are 16×16;
Latin glyphs are 8×16. The subset is distributed under SIL OFL 1.1;
see `OFL-1.1.txt`. This license applies to the font data.

Source: https://unifoundry.com/pub/unifont/unifont-16.0.04/font-builds/unifont-16.0.04.hex.gz

Copyright notice verified against the same release's `unifont-16.0.04.bdf.gz`.
Glyph extraction removes unused characters; no glyph shapes were modified.
The modified subset name is Archive Screen Bitmap.
