如何公平比较这三种方案

共同输入：每张图片解码一次，统一缩放至 48 × 48；忽略 alpha < 128 的像素。最多 5 个色群，忽略占比 < 1.5% 的色群。

现有 Wu：直接调用正式取色函数，取其未经背景适配的 dominant；先按 OKLab 距离 < 0.035 合并，再取面积最大者。

调整选色后的 Wu：沿用相同 Wu 色群；额外合并色相差 ≤ 18°、明度差 ≤ 0.22 的有彩色群（C ≥ 0.025），再按“面积 ×（0.9 + 0.1 × min(C / 0.12, 1)）”评分。黑白不被排除。

OKLab K-means：确定性的加权最远点初始化，最多 30 次 Lloyd 迭代；使用与调整后的 Wu 相同的合并和评分规则。两者差异主要来自聚类。

统一适配：固定 OKLCH 明度，保留色相；彩度取原始彩度与上限中的较小值，再通过降低彩度映射至 sRGB。主次文字 ≥ 4.5:1，控件 ≥ 3:1；数字基于实际合成与取整后的颜色。这里没有沿用正式 Wu 的背景压暗规则。

这是颜色比较工具；歌词、时间和播放图形为静态示意。没有音频播放、曲库读取、上传或偏好写入。相近结果也如实展示，不人为拉开差异。
