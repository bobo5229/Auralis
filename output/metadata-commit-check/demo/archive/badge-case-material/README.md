# 铝盒外框与黑色海绵内胆

独立材质与检视原型：铝盒、黑色海绵、取出后的残留压痕，以及徽章移动放大、绕自身竖轴翻转后悬浮检视的完整动线。

```powershell
node demo/archive/badge-case-material/serve.mjs
```

打开 <http://127.0.0.1:4198/>。可通过 `BADGE_CASE_PORT` 改变端口。全部字体、纹理、徽章图片均来自本地，无网络素材。

- 顶部切换小时、天数、专辑；单排排列，空间不足时支持触控板横滑、滚轮和两侧箭头。
- 左键单击一枚徽章：从原位置移动放大到中央，同时绕自身竖轴翻转一圈，途中可看见侧边和金属背面，最终转正。背景收藏盒适当压暗，原位置保留海绵凹痕。
- 悬停在放大的徽章上，随鼠标位置轻微倾斜，观察 GLSL 反光；离开后归正。检视层仅有徽章与图形关闭按钮，不显示详情文字。
- 点击空白、右上角关闭按钮或按 Esc，徽章缩小并回到原位；焦点也返回原按钮。键盘 Enter 可打开检视。
- 「全部取出／全部放回」保留为海绵材质观察操作；全部取出后点击某个空位可将对应徽章放回。
- 右下角切换深浅展示环境，铝盒与黑色海绵保持自身材料颜色。
- 小徽章使用既有 330×370 GLSL 导出 PNG；海绵使用一张共享 Canvas2D 画布。首次检视才创建一个 WebGL 上下文，后续选中徽章共用它。

本原型已迁入正式播放器：聆听档案 → 聆听纪念 → 查看全部。产品实现位于 `src/renderer/features/archive/`，运行不依赖此原型服务器；本目录保留为设计样板与历史性能对照。检视模块通过项目已有的 esbuild 和 Three.js 打包；修改检视源码后需要重启服务并刷新页面。

隔离 Electron 验证包括两部分：海绵、分类、滚动、键盘和约 1440／900／390px 布局见 `output/badge-case-material/performance-2026-10-25/material-validation/`（脚本 `output/badge-case-material/verify.mjs`）；检视的单击、正反面、悬停、静置停帧、提前退出、准备资源时取消、返回原位、尺寸变化与全部 11 枚徽章素材加载见同级 `inspection-validation/`（脚本 `output/badge-case-material/inspect.mjs`）。截图与 `report.json` 只代表此独立原型的运行结果。

## 检视与动效

- **核心动作**：拿起一枚收藏徽章，移动放大的同时绕自己的竖轴翻转一圈，展示正面、侧边、背面，最终停在正面。进入约 1080ms，移动逐渐减速，自转平滑加速再减速；放回约 420ms。过场中按 Esc 会从当前姿态返回，不额外补转一圈。
- **空间连续性**：从被点击图片的实际位置与尺寸起步；检视时保留收藏盒和残留压痕；回程对齐原位置，并恢复盒内静态图片。
- **材质**：正面直接复用产品的 `badgeShaders.ts` 和既有五张材质图。背面、倒角和厚度是本原型新增的通用三维模型，轮廓取自同一 SVG；背面为无文字拉丝金属底板与简洁别针结构，是设计示意，不是原资产已有的背面。
- **鼠标反馈**：只在放大徽章上响应，俯仰最高约 5.7°、左右倾斜最高约 6.9°。材质随三维法线受光变化，光源固定；鼠标离开后平滑归正。
- **预算与生命周期**：`badgeInspector.js` 管理弹层、过场、鼠标与焦点；`inspectRenderer.js` 管理几何、纹理及一个 WebGL 上下文。仅过场、鼠标移动和归正时绘制，稳定或页面隐藏后停止。减弱动效下直接进入正面，保留状态反馈并停止自转。
- **资源准备**：五张独立材质图并行加载；用现有 Three.js 的 `initTexture()` 和 `compileAsync()` 在翻转开始前完成纹理上传与程序准备。更换徽章时释放旧纹理；没有增加动画库或修改贴图分辨率。

## 材质与几何

`generate-materials.mjs` 用固定随机种子生成两张可平铺纹理。海绵是微孔高度场与固定左上受光，铝材是横向加工细纹；两者各以 2× 密度提供细节。生成记录位于 `assets/provenance.json`，不使用第三方纹理或修改徽章资产。

```powershell
node demo/archive/badge-case-material/generate-materials.mjs
```

海绵没有预先切出的槽口、槽壁或独立槽底。`distanceField.js` 从原徽章 SVG 外轮廓生成浮点距离场；`pressureSurface.js` 将其转成平滑的负高度场，坡面从徽章接触区域向外约 30px 连续恢复到原平面。海绵的同一张微孔纹理随压力轻微收缩、压实，避免出现镶嵌的另一块内衬。

亮度由两个独立因素共同决定：高度梯度决定坡面朝向与左上受光，压入深度决定环境光衰减，越深越暗。坡面向外逐渐恢复到未受压的亮度；不会绘制一圈固定黑色描边。名义深度 8px 是视觉近似，并非真实海绵材料参数。盒沿仍通过表面、倒角、内侧加工槽和前侧壁分层形成厚度。

放回时较快压下，拿起时以临界阻尼轻微回弹，最终保留原下陷深度的 82%，表现长时间受压后留下的痕迹。压痕不会在等待、切换分类或调整窗口后自动消失；不模拟数分钟的持续恢复。稳定后停止绘制，页面隐藏时暂停，减弱动效偏好下直接到达同样保留压痕的最终状态。材质渲染密度最高为 1.5×，与徽章 PNG 清晰度分别控制。

## 性能路径

- `pressureSurface.js` 保留 DOM 几何、压力状态与阻尼时钟；`pressurePainter.js` 是纯像素绘制内核；`pressureWorker.js` 在后台执行内核。主线程只提交压力值并显示局部像素，徽章翻转不再等待海绵计算。
- 静止区域保留在像素缓存中。每次只使压力变化的徽章边界区域失效，同时计入与它重叠的相邻压痕，保持原有的高度、受光、纹理压实和接触区域结果。
- 像素和几何数组使用可转移的 `ArrayBuffer` 交接。每一代画布最多一个绘制任务在途，更新积压时合并为最新状态；分类或尺寸重建后忽略旧代结果。离页时终止 Worker。
- Worker 不可用时复用同一个局部绘制内核在主线程运行，视觉和压力行为保持一致。`snapshot()` 的 `backend`、`animating`、`pendingPaint`、计算及主线程提交计时用于区分后台工作和动画停帧。
- 基线、局部缓存试验及最终复测保存在 `output/badge-case-material/performance-2026-10-25/`；性能采集期间不截图或编码图片。`pixel-equivalence.mjs` 用同一确定性时钟，将旧版与新版的完整 RGBA 像素和压力状态逐一比较。

实现依据：[Canvas 预渲染与分层](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas)、[Web Worker 的可转移对象](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Transferable_objects)、[Three.js 纹理初始化与程序预编译](https://threejs.org/docs/pages/WebGLRenderer.html)。

2026-10-25 同机隔离 Electron 复测（约 1440×900、DPR 1.5、RTX 5060 Laptop，前后各两次重复打开；测量期间没有截图或并行验证）：

| 指标                           | 优化前   | 优化后  |
| ------------------------------ | -------- | ------- |
| 动画更新间隔 P95               | 33.2ms   | 18.1ms  |
| 超过 25ms 的更新               | 65 / 130 | 0 / 130 |
| 翻转期间海绵主线程耗时，约每次 | 511ms    | 26ms    |
| 首次进入前准备，单次样本       | 207.5ms  | 187.5ms |
| 切换另一徽章的准备，单次样本   | 118.9ms  | 88.6ms  |

上述间隔是动画更新时刻，不等同屏幕实际呈现帧率。后台像素计算仍约 6.5ms／次；主线程只承担提交和显示。单枚变化时更新区域从整幅 736,434 像素缩小到 164,970 像素。两种后端各 9 个确定性像素场景均与旧版 RGBA 和压力状态完全一致；材质与检视分别通过 25 和 21 项运行检查。见[复测汇总](../../../output/badge-case-material/performance-2026-10-25/optimized-summary.json)，同一输出目录的 `optimization-before/` 和 `optimization-final/` 保留原始前后数据。

## Direction contract

- 模式：Experience；延续 Auralis 徽章的几何、配色、命名与通用字体规格。
- 首屏：一只横向、精致写实的银色铝盒，连续的黑色海绵内胆，一排带短名称的静态徽章。
- 材料：冷灰哑光拉丝铝、细密微孔海绵；固定左上受光，柔和的受压坡面，越深越暗，边缘没有切割线。
- 观察动作：拿起徽章后，轻微回弹并持续保留压痕；放回重新压下。分类切换与横向浏览均可实际操作。
- 检视：移动放大与竖轴翻转同步；正反面与侧边可见；停稳后鼠标微倾斜；无详情文字；空白或 Esc 放回。
- 范围：只新增本目录原型与相应验证输出；产品组件、真实用户数据与全局设计系统不变。
