# 珐琅徽章 demo

范围：`demo/archive/enamel-milestone/index.html` 及同目录样式、脚本。模式：Experience。

## Direction contract

THESIS：让一枚徽章本身证明 2.5D。SVG 平面提供精细几何与材质，CSS 透视、薄片叠层和空间位移提供可观察的厚度。

OWN-WORLD：继承用户参考的六边形、蓝色珐琅、银色隔线、幻彩嵌饰和透明罩面。深色展示台承托徽章，字体复用播放器本地字体。界面只提供观察物件所需的控制。

STORY：先欣赏完整徽章，再移动高光、调整视角、拆开结构，最后重播达成。所有里程碑值明确标为演示。

FIRST VIEWPORT：桌面左侧为约 480px 的主徽章，右侧为名称、条件、两种视图、三种配色和重播按钮。窄屏先显示徽章，控制区随后排列。五层构造的名称紧邻画面。

FORM：用户已指定的珐琅徽章观察台；精准的单物件技术原型，直接采用固定方向，不开展视觉方向抽签。代码原型为验证对象，不生成位图替代几何。

FINISH：按项目规则在同一会话完成浏览器自测、画面复查和局部设计记录；用户未授权代理或独立会话。保留既有未提交改动，交付本地入口、有效截图和实际验证范围。
