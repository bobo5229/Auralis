# 环境与操作

开发环境为 Windows 11 / PowerShell 7，使用 `npm.cmd` 避开当前环境的 npm executable shim 问题。Node、Electron、原生依赖版本及可用脚本以 package.json 和锁文件为准。

原生运行验证优先复用仍适用的 Electron ABI 匹配证据。二进制或运行环境变化、匹配状态未知时，在目标 Electron 中执行最小隔离原生调用，数据库可使用内存库。确认依赖缺失、损坏或 ABI 不匹配后，再准备或重建依赖，常用脚本见 package.json。

检查可生成预期缓存、构建输出和隔离测试数据，输出位置须避开验收源文件与真实用户数据。仅清理本次创建且范围已确认的临时产物，保留已有未知文件。

## Electron 启动时 GPU / Renderer 连续崩溃

- 遇到 `exitCode=-2147483645`（`0x80000003`）、软件 GL 回退失败和 `GPU process isn't usable` 时，结合安装目录 ACL、沙箱兼容性和对照证据定位根因。
- 权限修复须有当前对照证据并备份权限，仅处理 Electron 安装目录内已确认的问题授权，保留其他权限。禁止按 SID 前缀批量删除权限或对工作区、用户目录、磁盘递归重置权限。
- 软件渲染脚本同时关闭 GPU 沙箱，启动结果仅适用于该配置。修复须验证实际硬件渲染与沙箱状态，保留默认沙箱配置。

遇到上述症状时按需读取 [2026-09-28 Electron 启动崩溃复盘](../reviews/2026-09-28-electron-startup-acl-crash.md)，其中包含隔离对照、权限备份、修复验证和重建后复发的处理方法。
